# 民间故事形态学分析流程

本流程用于结构化分析民间故事，依据普罗普（Vladimir Propp）功能理论，包含七个分析步骤。

---

## 第一步：通读全文

- 把握故事大意（不提取）

---

## 第二步：划分轮次

1. 识别每个轮次的起点（∅/a/A）
2. 识别每个轮次的终点（W*/K*/Rs/T*）
3. 标注轮次间的六种结合方式
4. 标注轮次间的衔接要素 §（通报、看到、被带来、设宴）

---

## 第三步：逐句提取功能（核心步骤）

### ③ 匹配 31 项功能表

- 匹配成功 → 在已有的 31 个功能选择
- 匹配失败 → 触发同化判定（增加新的功能）

### ④ 同化判定（用于发现判定新功能）

1. **问 1**：这个动作承担了哪个已知功能的后果？
2. **问 2**：它的形式与已知品种是否不同？
3. **两者都满足** → 同化标注（后果相同 + 形式不同）
4. **后果不同** → 可能是真正的新功能

### ⑤ 辅助要素（每一句都要识别"辅助身份"）

| 标签 | 说明 |
|------|------|
| § | 衔接要素（与功能绑定或独立） |
| 同化 | 与 ④ 同步完成 |
| 三重化 | 同一功能重复第 3 次时标 |
| 倒置 | 方向反转（如 γ² 反向禁令） |
| 省略 | ? 与标准模板对照后回填（暂留，待第五步） |

### 【辅助标签的总作用】

```
功能 = 骨架（是什么）
辅助标签 = 定语（怎么发生的）
骨架 + 定语 = 完整描述
```

---

## 第四步：功能配对关系分析（先于图式）

- **必然配对**：γ-δ、H-I、J-Q、M-N、L-Ex
- **相对依赖**：A-K、A-Pr/Rs
- **自由组合**
- **同化配对**（若上一步标了同化，需重新审视配对类型）

---

## 第五步：图式合成

1. 按顺序书写功能
2. 标注轮次交织（用 | 或虚线）
3. 标注辅助要素（§、:、≈、倒置、?）
4. 与基本图式对照
5. 标出"省略"（该有但没有的功能，回填?）

---

## 第六步（可选）：角色行动圈分析

1. 七种角色各承担哪些功能？
2. 是否存在"一身二任"？
3. 是否存在"行动圈分配给若干角色"？

---

## 第七步：提取套路（你的扩展）

1. 抽象出可复用的功能组合
2. 与已知套路对比
3. 套路失真度评估（受同化与角色复合影响）

---

## 示例：牛郎织女的故事

### 第一层：结构（故事有几段）

```
第一轮：娶亲                                      第二轮：拆散
├── α 孤儿开局                                    ├── A 王母得知
├── a 哥嫂分家                                    ├── A+Pr 强行带走
├── A 赶牛郎出门                                  ├── C↑ 披牛皮追赶
├── F 老牛开口                                    ├── Pr 划银河
├── Pr 藏衣裳                                    ├── § 隔河相望
├── Rs 被迫留下                                  ├── Rs 鹊桥出现
├── E 求婚                                        └── W*≈ 七夕相会
├── W* 成婚
└── §B 幸福生活
```

### 第二层：功能（同化判定 + 辅助标签）

#### 句 6：织女无法返回天庭

| 项目 | 内容 |
|------|------|
| 动词 | 无法返回 |
| 意义 | 被困住 |
| 匹配 | 落空 → 触发同化 |
| 同化判定 | 问1 后果？→ Rs（追捕/逃亡）<br>问2 形式？→ 主动逃 vs 被动困（不同）<br>结论：Rs 的同化 |
| 辅助标签 | 同化（≈） |

#### 句 9：男耕女织幸福生活

| 项目 | 内容 |
|------|------|
| 动词 | 过 |
| 意义 | 陈述状态 |
| 匹配 | 落空 → 触发衔接 |
| 结论 | B² + §（双身份） |
| 辅助标签 | § |

### 第三层：配对关系

- **完整配对**：E—W*（求婚→成婚）
- **相对依赖**：A—Pr≈—C↑（加害→没收→追赶）
- **缺失配对**：
  - γ-δ（禁令→违禁）×
  - H-I（搏斗→胜利）×
  - K（消除）×

### 第四层：图式合成

```
[α a A F Pr≈ Rs≈ E W* §B]  [A Pr≈ C↑ Pr≈ § Rs≈ W*≈ §]
    第一轮（娶亲）              第二轮（拆散）
```

**对照标准模板**：α a A F Pr Rs E W* B

**找出省略**：γ-δ、H-I、K

### 第五层：角色行动圈

| 角色 | 承担功能 |
|------|----------|
| villain | 哥嫂（第一轮） + 王母（第二轮） |
| donor+helper | 老牛 |
| hero | 牛郎 |
| princess | 织女 |
| dispatcher | 王母 |

### 第六层：套路总结（还未转化成机器读取的语言）

| 项目 | 内容 |
|------|------|
| 套路名 | 鹊桥相会 |
| 核心组合 | Pr≈（骗走）→ Rs≈（被迫留下）→ W*≈（周期性相会） |
| 失真点 | Rs 同化（被动困 ≠ 主动逃）<br>B 替换（周期相会 ≠ 永久幸福） |
| 套路类型 | 悲剧变形 |
