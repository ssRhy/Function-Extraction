# 知乎短篇故事套路实验子集 v1

- 悬疑／惊悚：40 篇

抽样版本：zhihu-routine-subset-v1（固定 SHA-256 排序作为并列项复现规则）。

`manifest.csv` 适合表格查看，`manifest.json` 适合程序读取；每篇同时保留 TXT 正文与原始 JSON 元数据。
