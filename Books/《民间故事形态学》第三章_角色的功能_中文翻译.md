# 《民间故事形态学》

## 第三章　角色的功能

**作者：** 弗拉基米尔·雅可夫列维奇·普罗普（V. Propp）  
**翻译范围：** 原书正文第 25—65 页（PDF 第 51—92 页），含本章 7 条注释  

> **术语延续**：沿用前两章译名：*tale* = 故事；*folktale* = 民间故事；*fairy tale* = 神奇故事；*theme* = 情节；*motif* = 母题；*function* = 功能；*dramatis personae* = 角色；*absentation* = 离家外出；*interdiction* = 禁令；*violation* = 违禁；*villain* = 加害者；*reconnaissance* = 侦察；*delivery* = 泄漏；*complicity* = 顺从；*villainy* = 加害；*mediation* = 媒介、衔接环节；*donor* = 赠予者（提供者）；*hero* = 英雄；*magical agent/helper* = 魔法媒介 / 魔法助手；*spatial transference* = 空间转换；*struggle* = 搏斗；*branding* = 印记；*victory* = 胜利；*pursuit* = 追捕；*rescue* = 解救；*return* = 归来；*unrecognized arrival* = 未被识别的抵达；*unfounded claims* = 虚假的冒功；*difficult task* = 难题；*solution* = 解答；*recognition* = 相认；*exposure* = 揭穿；*transfiguration* = 变形；*punishment* = 惩罚；*wedding* = 成婚。各功能原文符号（如 β、γ、δ、ε、ζ、A、B、C、D、E、F、G、H、I、J、K、M、N、Pr、Q、Rs、T、U、W 等）在译文中照录。

本章中，我们将按照故事自身所规定的次序，逐一列举角色的功能。

对每一种功能，我们给出：（1）简要说明其本质的小结；（2）以一个词表达的简短定义；（3）约定的符号。（符号的引入，将使我们能够在后文对不同故事的结构作图式化的比较。）其后列举若干例子。这些例子大多远远不能穷尽我们的材料；它们只是被作为样品给出。例子被分成若干群；这些群相对于定义，是种相对于属的关系。基本的任务是提取“属”。对“种”的考察不能列入一般形态学所应处理的问题。“种”还可以进一步分为“变种”，而这便已是系统化的开始。下文所给出的排列并不追求这些目的。所引例子只应当用以说明，作为某一种“属”的单位，某一功能确实存在。如前所述，一切功能都纳入同一条连贯的故事线索之中。下面给出的这一系列功能，便是一般神奇故事的形态学基础。¹

故事通常以某种“初始情境”开始。家庭成员被一一列出，或者未来的英雄（例如一名士兵）只通过姓名或身份标识被简单引入。尽管这一情境不是一种功能，但它仍然是一个重要的形态学要素。故事开头的“种”只能放到本书末尾再加以考察。² 我们把这一要素称为**初始情境**，并赋予符号 **α**。

初始情境之后，便依次出现以下各项功能：

### I. 一名家庭成员离家外出
**（定义：离家外出，符号：β）**

1. 离家外出者可以是上一代的成员（β¹）。父母外出做工（113）。 “王子不得不远行，把妻子托付给陌生人照管”（265）。 “有一次，他（一个商人）动身到外国去做生意”（197）。通常的离家形式有：外出干活，去森林，出外经商，去打仗，“外出办事”。

2. 离家外出的强化形式是父母的亡故（β²）。

3. 有时是下一代成员离家外出（β³）。他们出门做客（101）、钓鱼（108）、散步（137）、去采浆果（244）。

### II. 对英雄施加一道禁令
**（定义：禁令，符号：γ）**

1. （γ¹） “你不可窥看这间小屋子”（159）。 “照看好你弟弟，不要走出院子”（113）。 “若芭芭雅嘎来了，你什么也不要说，安静地待着”（106）。 “王子常常想劝阻她，命令她不要离开那座高塔”，等等（265）。 不许外出的禁令，有时被加强为把孩子关进堡垒（201）。 反过来，有时禁令以减弱的形式出现，即表现为请求或劝告：母亲试图劝儿子不要外出钓鱼；“你年纪还小”，等等（108）。 一般来说，故事先提及离家外出，随后再提及禁令。当然，实际的事件顺序正好相反。禁令也可以在没有离家外出与之相连的情况下单独出现：“不要摘苹果”（230）； “不要拾那根金色的羽毛”（169）； “不要打开那只箱子”（219）； “不要吻你姐姐”（219）。

2. 禁令的颠倒形式表现为命令或建议（γ²）。“把早饭送到地里去”（133）。 “带你弟弟一起进林子”（244）。

> **插话**：为便于理解，这里稍作旁逸。故事在稍后会突然降临灾祸（但并非毫无准备）。与此相应，初始情境给出一种特殊的、有时甚至刻意强调的幸福生活。沙皇拥有金苹果的奇妙园林；老两口钟爱他们的伊瓦谢伊卡，如此等等。一种特别的形式是农业丰收：农夫和他的儿子们在割草场上喜获丰收；常可看到关于播种与极佳出苗的描写。这种幸福，自然为接踵而至的不幸提供了反衬。这场不幸的幽灵已经在幸福家庭上方无形地徘徊。由这一情境，便衍生出“不得外出”之类的禁令。长者的离家外出，本身便为不幸做好了准备，创造了可乘之机。孩子们在父母离去或亡故后，便只能自行其是。命令常常扮演禁令的角色。如果孩子们被催促到地里或林中去，那么遵从这一命令，与违犯“不得下地进林”的禁令，具有完全相同的后果。

### III. 禁令被违犯
**（定义：违禁，符号：δ）**

违禁的形式与禁令的形式相对应。功能 II 与 III 构成一个成对要素。这一对的第二半有时可独立存在（沙皇的女儿们走进园子 [88]；她们回家晚了）。这里，对“晚归”的禁令被略去了。被执行了的命令，正如前文所示，等于被违犯的禁令。

至此，一个新角色——可称之为加害者——登场。他的任务是搅扰一个幸福家庭的安宁，制造某种不幸、损害或祸害。加害者可以是龙、魔鬼、强盗、女巫或继母等。（至于新角色一般如何出现在行动进程之中这一问题，已另列专章。）于是，加害者已经登场。他徒步而来，潜行而至，或者从天而降，等等，随后便开始行动。

### IV. 加害者试图侦察
**（定义：侦察，符号：ε）**

1. 侦察的目的，在于探明孩子们的所在，有时也在于打探珍贵物品的下落，等等（ε¹）。一头熊说：“谁能告诉我沙皇的孩子们怎么样了？他们消失到哪儿去了？”（201）；一名文书问道：“你们从哪儿弄来这些宝石？”（197）；一位神父在告解时问：“你怎么能这么快就好了？”（258）；一位公主问：“商人伊万，告诉我，你的智慧在哪里？”（209）；“这条母狗靠什么活着？”雅吉什娜心里盘算着。她派出独眼婆、双眼婆和三眼婆前去侦察（101）。

2. 侦察的颠倒形式，是预定的受害者向加害者发问（ε²）。“你的死在哪里，科谢伊？”（156）。“你有一匹多快的马呀！哪儿还能再找到一匹能跑赢你的？”（160）。

3. 在个别情形中，可看到通过其他人物进行的侦察形式（ε³）。

### V. 加害者获得关于其受害者的情况
**（定义：泄漏，符号：ζ）**

1. 加害者直接得到对其问题的答复（ζ¹）。 凿子回答熊道：“把我拿到院子里，扔到地上去；我插的地方，那便是蜂巢。” 对于文书关于宝石的问题，商人的妻子答道：“啊，那是我们家的母鸡下的”，等等。我们再一次面对成对的功能。它们常常以对话的形式出现。顺便一提，继母与镜子的对话也属于此类。虽然继母并未直接询问继女的事，镜子却回答她：“您的美貌自不待言；但您有一位继女，她住在深林骑士那里，而且她甚至比您还要美丽。” 与其他类似情形一样，这一对功能中的后半有时可以独立存在。在这些情形下，泄漏以无意识的举动出现：母亲大声呼唤儿子回家，由此把儿子的所在暴露给女巫（108）。一位老人得到了一只神奇的口袋；他从袋中取出一些食物款待教母，从而把口袋的秘密泄漏给了她（187）。

2—3. 颠倒或其他形式的探询，引出相应的回答（ζ²—ζ³）。 科谢伊透露自己死亡的秘密（156），透露快马的秘密（159），如此等等。

### VI. 加害者试图欺骗受害者，以便将他本人或他的财物据为己有
**（定义：欺骗，符号：η）**

加害者首先乔装打扮。一条龙变成一只金色的山羊（162），或一位英俊的青年（204）；一个女巫装作一位“慈祥的老太太”（265），并模仿母亲的声音（108）；一个神父披上一张山羊皮（258）；一个小偷装作讨饭的老婆子（189）。随后才是这一功能本身。

1. 加害者用劝说（η¹）。 一个女巫设法让人收下一枚戒指（114）；一位教母建议洗一次蒸汽浴（187）；一个女巫建议脱掉衣服（264），建议到池塘中洗浴（265）；一个乞丐前来求乞（189）。

2. 加害者通过直接动用魔法手段行动（η²）。 继母给继子服下一剂安眠药，把一根有魔法的针别进他的衣服（232）。

3. 加害者采用其他欺骗或强制手段（η³）。 邪恶的姐妹们在费尼斯特将要飞过的窗户周围安插刀子和尖刺（234）。 一条龙重新摆弄本该指示小姑娘去哥哥们那里的木屑（133）。

### VII. 受害者顺从了欺骗，从而不自觉地帮助了他的敌人
**（定义：顺从，符号：θ）**

1. 英雄接受了加害者的全部劝说（即：收下戒指、去洗蒸汽浴、去游泳，等等）。 我们注意到，禁令总是被违反，反之，欺骗性的提议也总是被接受并被执行（θ¹）。

2—3. 英雄机械地对魔法或其他手段作出反应（即：沉睡下去、受伤，等等）。 人们可以观察到，这一功能也能单独存在：没有人把英雄哄入睡，他自己却忽然睡了过去，以便——自然——为加害者提供方便（θ²—θ³）。

欺骗性提议及其相应接受的一种特殊形式，是“欺骗性的约定”。（“把你家里还不知道自己藏着的东西交出来。”）这类情形中的同意是被迫作出的，加害者利用受害者所陷入的某种困境：失散的羊群、极度贫困，等等。有时，困境本身正是加害者故意造成的。（熊抓住沙皇的胡子 [201]。）这一要素可以界定为**预备性的不幸**。（符号：**λ**，以区别于其他欺骗形式。）

### VIII. 加害者给一名家庭成员造成损害或伤害
**（定义：加害，符号：A）**

这一功能极为重要，因为正是经由它，故事才产生出真正的运动。离家外出、违犯禁令、泄漏、欺骗得逞——这一切都为这一功能作了铺垫，或创造出它发生的可能性，或者至少使它更易于发生。因此，前七项功能可以视作故事的“准备部分”，而纠葛则由一项加害行为开始。

加害的形式极其多样：

1. **绑架人**（A¹）。 一条龙劫走沙皇的女儿（131）；一个农夫的女儿（133）；一个女巫劫走一个男孩（108）；哥哥们劫走弟弟的新娘（168）。

2. **夺取或抢走魔法媒介**（A²）。 “不起眼的家伙”夺走一只魔法小匣（189）；一位公主夺走一件魔法衬衣（208）；指头大的农夫盗走一匹魔法马（138）。

   **2a.** 对魔法助手的强行劫夺，构成这一形式的特殊子类（A¹¹）。 一个继母下令宰杀一头奇迹般的奶牛（100、101）。 一个文书下令宰杀一只魔法鸭或魔法鸡（196、197）。

3. **劫掠或糟蹋庄稼**（A³）。 一匹马吃光一堆干草（105）。 一头熊偷走燕麦（143）。 一只鹤偷走豌豆（186）。

4. **夺走日光**（A⁴）。 这只出现一次（135）。

5. **以其他形式劫掠**（A⁵）。 劫夺的对象千差万别，无须逐项登记。后文将可以看到，劫夺的对象并不影响行动的进程。从逻辑上说，更恰当的做法是将一切劫夺视为加害的同一种形式，而把其具体形态（按对象细分）视为子类而非类。然而，从技术上看，分离出几种最重要的形式并将其余概括处理更为有用。例：一头火鸟偷走金苹果（168）；一头鼬兽每夜从沙皇的动物园中叼走动物（132）；将军夺走国王的（非魔法）宝剑（259）；等等。

6. **造成身体伤害**（A⁶）。 一个女仆挖出女主人的双眼（127）。 一位公主砍掉卡通玛的双腿（198）。 有趣的是，从形态学的观点看，这些形式也是劫夺的一种形态。例如，挖出的眼睛被女仆装进口袋并带走，因此其获取方式与一般被劫夺之物相同，并被安置在恰当的位置。被挖出的心脏也与此相同。

7. **造成突然的消失**（A⁷）。 通常这种消失是施用魔法或欺骗手段的结果：继母让继子沉睡——他的新娘便永远消失（232）。 姐妹们把刀子和针插在费尼斯特将要飞来的窗户上——他伤了翅膀，从此永远消失（234）。 一位妻子骑着魔法飞毯离开丈夫（192）。 第 267 号故事展示了一种有趣的形式：在那里，消失是由英雄本人造成的：他烧掉了被施了魔法的妻子身上的（外层）皮，她便永远消失。 第 219 号故事中的一例特殊情况，也可有条件地归入此类：一记被施了魔法的吻，使王子完全忘记了未婚妻。在这种情形下，受害者是那位失去未婚夫的新娘（A⁸）。

8. **索取或诱拐受害者**（A⁸）。 通常这一形式是欺骗性约定的结果。 海王要求得到沙皇的儿子，他便离开了家（219）。

9. **驱逐某人**（A⁹）。 继母把继女赶出家门（95）；一个神父把外孙赶走（143）。

10. **命令把某人扔进海里**（A¹⁰）。 一位沙皇把女儿和女婿放进一只木桶，并下令把木桶抛入大海（165）。 父母把熟睡的儿子放进小船，放船出海（247）。

11. **对某人或某物施咒**（A¹¹）。 应当在此指出，加害者常常同时做出两三种损害行为。有些形式很少独立出现，而表现出与其他形式相结合的倾向。施咒便属于这一类。一位妻子把丈夫变成一条狗，再把他赶走（即 A¹¹ A⁹）；继母把继女变成一只猞猁，再把她赶走（266）。 即使在新娘变成一只鸭子飞走的情形下，实际上我们也面对一个驱逐事件，虽然故事并未明说（264、265）。

12. **进行替换**（A¹²）。 这一形式也多为伴随形式。一位奶妈把新娘变成一只小鸭，而把自己的女儿顶替到新娘的位置（A¹¹ A¹²；264）。 一个使女弄瞎沙皇的新娘，再冒充她充当新娘（A¹² A⁶；127）。

13. **命令行凶杀人**（A¹³）。 这一形式在本质上是一种变体（强化）的驱逐：继母命令一名仆人在外出散步时杀掉继女（210）。 一位公主命令仆从把丈夫拖入森林杀掉（192）。 这种情形下，通常还要求呈上受害者的心和肝。

14. **亲手行凶杀人**（A¹⁴）。 这通常也只是其他加害行为的伴随形式，用来加强它们。一位公主夺走丈夫的魔法衬衣，随后把他杀死（即 A¹⁴ A²；209）。 哥哥们杀死弟弟，又劫走他的新娘（即 A¹⁴ A¹；168）。 姐姐抢走弟弟的浆果，又把他杀死（244）。

15. **监禁或扣押某人**（A¹⁵）。 公主把伊万关入地牢（185）。 海王将谢缅拘禁起来（259）。

16. **以强迫婚姻相威胁**（A¹⁶）。 一条龙要求把沙皇的女儿许配给自己为妻（125）。  
    **16a.** 这一形式在亲属之间发生（A¹⁶¹）。 一个哥哥要娶自己的妹妹（114）。

17. **以食人相威胁**（A¹⁷）。 一条龙要求把沙皇的女儿许配给自己充作晚餐（171）。 一条龙已经吃光村里所有的人，最后剩下的一个农民也受到同样的威胁（149）。  
    **17a.** 这一形式在亲属之间发生（A¹⁷¹¹）。 一个姐姐打算吃掉自己的弟弟（93）。

18. **夜间施虐**（A¹⁸）。 一条龙（192）或一个魔鬼（115）在夜间虐待公主；一个女巫飞到一个姑娘身边，吸吮她的乳房（198）。

19. **宣战**（A¹⁹）。 一位邻近的沙皇宣战（161）；同样，一条龙蹂躏诸国（137）。

至此，在所选材料的范围内，加害的形式已经穷尽。然而，远非所有的故事都从不幸降临开始。还有一些别的开端，它们常常与以（A）开头的故事呈现出同样的发展过程。考察这种现象，我们可以看到，这些故事从一个“匮乏”或“缺乏”的情境出发，正是这一情境导致了类似加害情形中的追寻。因此我们可以作出结论：**匮乏**可以被视为形态学上与劫夺等价的要素。

试看以下情形：一位公主夺走了伊万的护符。劫夺的结果，是伊万失去了护符。于是我们看到，故事在略去加害的情况下，常常直接以匮乏开始：伊万渴望得到一柄魔法军刀或一匹魔法马，等等。匮乏与劫夺一样，决定着纠葛的下一节点：伊万上路去追寻。关于劫走新娘这件事，我们也可以和“仅仅缺少新娘”的情形作同样的说明。前一种情形中，给出了某种行为，由此造成一种匮乏，并引起追寻；后一种情形中，预先就摆好了某种匮乏，它同样引起追寻。前一种情形中，匮乏从外部被造成；后一种情形中，匮乏从内部被意识到。

我们完全承认，“缺乏”（nedostača）和“匮乏”（nexvodka）这两个词并不完全令人满意。但在俄语中，并没有一个词能完全而精确地表达这一概念。“缺少”（nedostatok）听起来稍好，但它具有一种不适合这一概念的特别含义。这种缺乏，可以比作一串数字中表示某个确定值的零。这一特征可以按如下方式表述：

### VIIIa. 家中一名成员缺少某物，或渴望得到某物
**（定义：匮乏，符号：a）**

这些实例很难顺利地归类。可以按实现匮乏的形式加以细分（参见第 53—55 页）；但此处只按匮乏的对象作出划分即可。我们可以登记以下几类形式：

1. **缺少新娘**（或朋友，或广义上的人）。这种匮乏有时被描写得相当鲜明（英雄打算去寻觅新娘），有时甚至根本不出现于言辞之中。英雄未婚，因此外出寻觅新娘——由此，故事便获得了开端（a¹）。
2. **需要魔法媒介**。例如：苹果、水、马、军刀，等等（a²）。³
3. **缺少奇物**（不带魔法力量），如火鸟、金羽鸭、奇中奇，等等（a³）。
4. **特殊形式**：装着科谢伊之死的魔法蛋（或装着公主之爱的魔法蛋）尚付阙如（a⁴）。
5. **理性化的形式**：缺少钱财、生计手段等等（a⁵）。我们注意到，这种来自日常生活的开端，有时发展得相当神奇。
6. **其他各种形式**（a⁶）。

正如劫夺的对象并不决定故事的结构，匮乏的对象同样不决定故事的结构。因此，为形态学的一般目的，我们不必将所有实例系统化。只需择取最关紧要的几类，其余概括处理即可。

这里不可避免地产生以下问题：远非所有故事都以损害或刚才所描述的那种开端为开头。傻瓜叶梅利亚的故事以傻瓜钓上一条梭鱼为开头，而全然不是以加害行为为开头，等等。然而，在比较多篇故事之后便可看出，本属于故事中段的要素有时被移到了开头。这里正是这种情况。捉到一只动物并把它放生，是典型的中段要素，后文我们将会看到。一般而言，每篇我们所考察类型的故事，都需要 A 或 a 这两个要素之一。其他形式的纠葛并不存在。

### IX. 不幸或匮乏被披露；英雄接到请求或命令；他被允许出发或被派遣
**（定义：媒介，衔接环节，符号：B）**

这一功能把英雄引入故事之中。若作最精细的分析，这一功能本可以再细分，但对我们的目的来说这并非必要。故事中的英雄可以有两种类型：

1. 若一名少女被劫走，并从她父亲（以及听众）的视野中消失，而伊万出发去寻她，那么，故事的英雄是伊万，而不是被劫走的少女。这一类英雄可以称为**追寻者**。
2. 若一名少女或少年被劫走或被驱逐，而叙事的线索系于他或她的命运，与留在家中的人无关，那么，故事的英雄就是那位被劫走或被驱逐的男孩或女孩。这类故事中没有追寻者。这一类英雄可以称为**受害者**。⁴

这两类英雄的故事是否以同样的方式发展，后文自会明白。在我们的材料中，没有同时以追寻者和受害者为线索的故事（参见《鲁斯兰与柳德米拉》）。两种情形下都存在一个媒介环节。这一环节的意义在于：英雄离家出走是由它所引发的。

1. **发出求救呼唤，因而派遣英雄**（B¹）。 呼唤通常由沙皇发出，并伴随以许诺。

2. **英雄直接被派遣**（B²）。 派遣以命令或请求的形式呈现。前者有时伴随威胁，后者则伴随许诺。有时威胁与许诺兼而有之。

3. **英雄被允许离家**（B³）。 这种情形下，离家的主动权常常属于英雄本人，而非派遣者。父母给予祝福。英雄有时并不透露他外出的真实目的：他请求允许出去走走，等等，实际上却是为了去战斗。

4. **宣布不幸的消息**（B⁴）。 一位母亲把发生在儿子出生之前的女儿被劫一事告诉儿子。儿子便出发去寻姐姐，并未由母亲请求他这样做（133）。但更常见的情形是，不幸的消息不是来自父母，而是来自各种老妇、路上偶遇之人，等等。

以上四种形式都属于追寻者英雄。接下来的形式则直接关系到受害者英雄。故事的结构要求英雄无论如何都必须离开家。如果这一点不是通过某种加害行为而完成的，故事便会借助衔接环节来达成。

5. **被驱逐的英雄被带离家门**（B⁵）：父亲把被继母驱逐的女儿带进森林。这种形式在很多方面都很有趣。从逻辑上说，父亲的行动是不必要的；女儿本可以自己走进森林。但故事要求在衔接环节中有一对父母—派遣者。可以证明，这一形式是一种次生形态，但这不属于一般形态学的目的。应当注意的是：

   在被龙索要公主的情形中，也使用了“运送”：她被带至海边。然而在后一种情形中，同时发出了求救呼唤。行动的进程由呼唤决定，而非由带至海边决定。这就解释了为何在这些情形中“运送”不能归入衔接环节。

6. **被判死刑的英雄被暗中释放**（B⁶）。 一个厨子或一名弓箭手饶过了一个女孩（或男孩），放了她；为了取得杀人证据，他们捕杀一只动物，取其心和肝（210、197）。如前所述，B 项被定义为引起英雄离家出走的因素。派遣呈现的是“出走的必要性”，而这里给出的则是“出走的可能性”。前一种情形属于追寻者英雄，后一种适用于受害者英雄。

7. **悲歌被唱出**（B⁷）。 这一形式特定于凶杀（由幸存的兄弟等人唱出）；特定于伴随驱逐的咒语，也特定于替换。借助这一方式，不幸被披露出来，从而引发反制行动。

### X. 追寻者同意或决定进行反制
**（定义：开始反制，符号：C）**

这一刻可用这样的话语来表达，例如：“请允许我们前去寻找您的公主”，等等。有时这一刻并不以言辞出现，但意志上的决定自然先于寻找。这一刻仅属于以英雄为追寻者的故事。被驱逐者、被战胜者、被施咒者、被替换者，都没有朝向解放的意志愿望，在这种情形中，这一要素便告阙如。

### XI. 英雄离家
**（定义：离家，符号：↑）**

这里的“离家”不同于先前以 β 表示的“暂时外出”。追寻者英雄和受害者英雄的离家也不相同：前者的离家以寻找为目标，后者的离家则是一段并无寻找的旅程的开端，其上等待着英雄的是种种奇遇。必须记住：若少女被劫走，而追寻者前去追赶，那么就有两个角色离开了家。但是故事实际展开的线索，实际是追寻者的线索。举例来说，若一个女孩被赶出家门，且没有追寻者，那么叙事便是沿着受害者英雄的线索展开。符号 ↑ 表示英雄的行程，不论他是不是追寻者。在某些故事中，英雄并不发生空间上的转移，全部行动发生于同一地点。有时恰恰相反，离家还被强化为逃奔。

A、B、C、↑ 几个要素构成了**纠葛**。此后，行动的进程便展开。

至此，一个新角色登场：这一人物可以称为**赠予者**，更准确地说，是**提供者**。通常他是在偶然的场合被遇到的——在森林里，在路边，等等。（参见第六章，关于角色登场形式的论述。）正是从他那里，无论追寻者英雄还是受害者英雄，获得了某种媒介（通常是魔法性质的），这种媒介使不幸得以最终解除。但在真正获得魔法媒介之前，英雄须经历多种多样的行动；这些行动的结果都使魔法媒介落入他手中。

### XII. 英雄被赠予者考验、盘问、攻击等等，为其最终获得魔法媒介或助手作准备
**（定义：赠予者的第一功能，符号：D）**

1. **赠予者考验英雄**（D¹）。 一个女巫让一个女孩去做家务（102）。 林中的骑士们提议，让英雄为他们服务三年。英雄要在一位商人手下服务三年（这是日常生活的理性化形式）（115）。 英雄须三年无偿在渡口充当船夫（138）。 英雄必须聆听古斯里琴的演奏而不致入睡（216）。 苹果树、小河和炉灶提供一顿简单的饭食（113）。 一个女巫提出让她与女儿同床共寝（171）。 一条龙建议搬起一块重石（128）。有时这一请求被镌刻在石头上；有时兄弟们找到大石头后自己试着去举起它。 一个女巫提出让她看管一群母马（159），等等。

2. **赠予者问候并盘问英雄**（D²）。 这一形式可以视为考验的减弱形式。问候和盘问在前述形式中也有出现，但在那里，它们并不具有考验的性质，而只是先于考验。这里则没有直接的考验，盘问承担了间接考验的角色。如果英雄无礼作答，他便一无所获；如果他恭敬作答，便会得到一匹马、一柄军刀，等等。

3. **垂死或亡故之人请求他人提供服务**（D³）。 这一形式有时也带有考验的色彩。一头母牛提出请求：“不要吃我的肉，而是把我的骨头收起来，用手帕包好，埋在园子里，不要忘了我，每天早晨给它们浇水”（100）。 第 202 号故事中的公牛提出类似的请求。 第 179 号故事展示了另一种临终愿望的形式：一个垂死的父亲嘱托儿子们在他坟旁守夜三个晚上。

4. **囚徒请求获释**（D⁴）。 小铜人被抓作俘虏，请求释放他（125）。 一个魔鬼被关在塔中，请求一名士兵放他出来（236）。 一个从水中打捞出来的罐子请求被打碎——即罐中之灵请求获释（195）。

   **4***.** 同上，并伴随对赠予者的预先监禁（D⁴*）。 例如，在第 123 号故事中，一个林中精灵被捉住，这件事本身不能被视为一项独立功能：它只是为随后囚徒的请求作铺垫。

5. **英雄被请求施以恩慈**（D⁵）。 这一形式可以视为前一项的子类。它或者在捉住之后出现，或者在英雄瞄准一只动物准备击杀时出现。英雄捉到一条梭鱼，梭鱼请求他放生（166）；英雄瞄准几只动物，它们请求饶命（156）。

6. **争执者请求划分财产**（D⁶）。 两个巨人请求把一根拐杖和一把扫帚在他们之间平分（185）。 争执者并不总是开口请求：英雄有时主动提出划分（D⁶¹）。 野兽不能分享猎物；英雄便对猎物作出分配（162）。

7. **其他请求**（D⁷）。 严格说来，请求本身构成一个独立的类，而具体类型构成子类；但为了避免过于繁琐的符号体系，可以姑且将所有这些变体各自视作一类。提取出基本形式后，其余可作概括处理。老鼠请求被喂养（102）；小偷请求被劫者替他搬运赃物（238）。 下面是一个可立即归入两类的例子：一只小雌狐被捉住；她请求：“不要杀我（恩慈请求，D⁵），给我用一点黄油煎一只肥嫩的母鸡”（第二次请求，D⁷）。 由于此前已先有监禁，故这一完整事件的符号为 *D⁷⁸。 一个不同性质的、同样涉及求助者受到威胁或陷入困境的例子：英雄偷走一个女浴者的衣服，她请求他归还（219）。 有时困境仅自发出现，而无须明确提出请求（雏鸟被雨淋湿，孩子们折磨一只小猫）。在这些情形中，英雄面前出现了提供帮助的可能性。从客观上看，这就相当于一项考验，尽管在主观上英雄并未意识到它是考验（D⁷）。

8. **敌对生物试图毁灭英雄**（D⁸）。 一个女巫试图把英雄送进炉子（108）。 一个女巫试图在夜间斩首英雄们（105）。 一位主人在夜间试图把他的客人们喂给老鼠（216）。 一位魔法师试图把英雄单独留在山上以毁灭他（243）。

9. **敌对生物与英雄交战**（D⁹）。 一个女巫与英雄搏斗。在林间小屋里英雄与各种林中居民之间的搏斗，极为常见。这里的搏斗具有斗殴或格斗的性质。

10. **魔法媒介被出示给英雄，以作交换之用**（D¹⁰）。 一个强盗出示一根木棒（215）；商人们展示奇物（216）；一位老人展示一柄剑（270）。他们提出以这些物品作交换。

### XIII. 英雄对未来的赠予者的行为作出反应
**（定义：英雄的反应，符号：E）**

在大多数情形下，反应或是肯定的，或是否定的。

1. 英雄经受住（或未能经受住）考验（E¹）。
2. 英雄回答（或没有回答）问候（E²）。
3. 他为亡者提供服务（或未提供）（E³）。
4. 他释放囚徒（E⁴）。
5. 他对求助者施以恩慈（E⁵）。
6. 他完成划分，并使争执者和解（E⁶）。 争执者的请求（或者只是并无请求的争吵）更常引出另一种反应：英雄欺骗争执者，例如让他们追逐他射向远处的箭；与此同时，他自己把争执的对象夺走（E⁷¹）。

7. **英雄执行其他某种服务**（E⁷）。 有时这些服务是对请求的回应；有时纯粹出于英雄的善心。一个姑娘款待过往的乞丐（114）。 一种特殊子类可以由具有宗教性质的形式构成。英雄焚一桶乳香以赞美上帝。一段祷文也可以归入此类（115）。

8. **英雄以其对手所用的同样手段自救**（E⁸）。 他让女巫示范如何爬进炉子，自己把她塞了进去（108）。 英雄们暗中与女巫的女儿们互换衣服；女巫便杀掉了她们，英雄得以脱身（105）。 魔法师本人被困在他本想把英雄丢下的山上（243）。

9. **英雄战胜（或未能战胜）对手**（E⁹）。

10. **英雄同意交换，但立即动用所换之物的魔力来对付交换者**（E¹⁰）。 一位老人提出以其魔法剑换哥萨克的一只魔法桶。哥萨克完成了交换，随即命令那把剑把老人的头砍下，魔法桶也失而复得（270）。

### XIV. 英雄获得对一种魔法媒介的使用
**（定义：魔法媒介的获得或接受，符号：F）**

下列各类事物可以充当魔法媒介：（1）动物（一匹马、一只鹰，等等）；（2）可以从中召出魔法助手的物品（一块燧石，内藏一匹骏马；一只戒指，内藏数位青年）；（3）具有魔法属性的物品，如木棒、宝剑、古斯里琴、宝球，以及许多其他东西；（4）直接赋予的能力或禀赋，例如变身为动物的能力，等等。所有这些被传递的对象，我们都姑且称之为“魔法媒介”。⁵ 它们的传递方式有如下几种：

1. **媒介被直接移交**（F¹）。 这类移交行为往往具有奖赏的性质：一位老人把一匹马作为礼物相赠；林中的动物提供它们的幼崽，等等。有时英雄并没有得到某种动物供自己直接使用，而是获得了变身为它的能力（详见第六章）。一些故事以奖赏的环节结束。在这些情形下，所赠之物具有某种物质价值而非魔法性质（F¹⁻）。如果英雄的反应是否定的，那么移交可能不会发生（F 负），或者代之以残酷的报复：英雄被吞噬、被冻僵、被从背上剥下皮条、被扔到石头底下，等等（F 反）。

2. **媒介被指示出来**（F²）。 一位老妇指出一棵橡树，树下停着一艘会飞的船（144）。一位老人指出一个农夫，从他那里可以得到一匹魔法马（138）。

3. **媒介被制备出来**（F³）。 “魔法师走到海岸上，在沙地上画出一条船，对他们说：‘弟兄们，你们看见这条船了吗？’‘看见了。’‘上船吧。’”（138）。

4. **媒介被出售和购买**（F⁴）。 英雄买下一只魔法母鸡（197）；他买下一只魔法狗和一只魔法猫（190），等等。介于购买与制备之间的过渡形式是“依订单制备”：英雄向一位铁匠订制一条锁链（105）。（这一例的符号：F⁴⁸。）

5. **媒介偶然落入英雄之手（被英雄发现）**（F⁵）。 伊万看到田野里有一匹马，便骑了上去（132）；他来到一棵结着魔法苹果的树下（192）。

6. **媒介自行突然出现**（F⁶）。 一段阶梯忽然出现，沿着山坡向上延伸（156）。 从地里自行长出的媒介构成“自行出现”的特殊形式（F⁶*），它们可以是魔法灌木（100、101）、枝条、一只狗和一匹马（201），或者一个矮人。

7. **媒介被食用或饮用**（F⁷）。 严格说来，这并非一种传递形式，但可以有条件地与上述各例相并列。三种饮料使饮用者获得异乎寻常的力量（125）；食用鸟的内脏使英雄们获得各种魔法属性（195）。

8. **媒介被夺走**（F⁸）。 英雄从一个女巫那里偷走一匹马（159）；他夺走争执中的对象（197）。 用魔法媒介对付交出它们的人，以及收回已经赠出的物品，也可以视为夺取的一种特殊形式。

9. **各类角色自荐供英雄差遣**（F⁹）。 例如，动物可以把自己的幼崽送给英雄，也可以向英雄提供自己的服务——可以说是把自己当作礼物送来。让我们比较以下这些情形：一匹骏马并非总是直接被赠予，或藏于一块燧石之中。有时赠予者只是把一段咒语告诉英雄，使英雄可以召出该马。在后一种情形中，伊万实际上并没有得到任何东西：他只是得到了差遣一位助手的权利。当求助者向伊万提供使用他的权利时，情况也相同：梭鱼告诉伊万一则咒语，使他可以召它出来（“只要说：‘奉梭鱼之命……’”）。如果连咒语也被省略，动物只是简单地说：“将来我会有用”，那么我们面对的仍然是英雄从动物形态的魔法媒介处获得助力的那一刻。此后，它便会成为伊万的助手（F⁹）。 许多魔法生物常常毫无预警地忽然出现，或在路上与英雄相遇，提供服务并被接受为助手（F⁹ᵇ）。这些往往是有异禀的英雄，或具有各种魔法属性的角色（巨食者、巨饮者、裂响的严寒老人）。

> 在这里，继续登记各项功能之前，可以提出如下问题：要素 D（传递前的准备）与 F（传递本身）以怎样的组合出现？⁶ 我们只需指出，在英雄作出否定反应的情况下，只出现 F 负（不发生传递），或 F 反（不幸的英雄受到严酷惩罚）。在英雄作出肯定反应的情况下，则出现如图 1 所示的种种组合。

从这一图式可以看出，连接极其多样，因此可以在整体上确定出某种形式对另一种形式相当广泛的替换性。然而，如果更仔细地审视这一图式，便会立刻觉察到若干连接的缺失。这种缺失，一部分可由材料不足来解释，但某些组合在逻辑上本就不可能。因此，我们得出结论：存在若干“连接类型”。若按魔法媒介的传递形式来划分类型，便可以分出两种连接类型：

1. **魔法媒介的夺取**，与毁掉英雄的企图（活烤等）、划分请求或交换提议相联系。
2. **其他一切传递和接受的形式**，与一切其他的准备形式相联系。划分的请求若划分真的完成，便属于第二类；若争执者受骗，则属于第一类。还可以观察到，魔法媒介或助手的**发现**、**购买**和**自行出现**，最常在没有丝毫准备的情况下出现。它们是原初形态。但若它们也有准备，则这种准备属于第二类，而非第一类。

> 在此可以顺便谈及赠予者的性质问题。第二类最常呈现出友好的赠予者（除非赠予者是不情愿地或在搏斗之后交出魔法媒介），而第一类则表现出非友好的（或至少是受骗的）赠予者。这些赠予者并非真正意义上的赠予者，而是不情愿地向英雄提供了什么东西。在每一种类型之内，所有组合——不论实际出现与否——都是可能的、合乎逻辑的。例如，无论是苛刻的还是感激的赠予者，都可以给予、揭示、出售或制备一种媒介，或者容许英雄自行发现该媒介，等等。另一方面，一位受骗的赠予者所拥有的媒介，则只能被偷走或被强行取走。这些类型之外的组合则是不合逻辑的。例如，若英雄在替一个女巫完成一项艰巨任务之后，又从她那里偷走一匹小马驹，这在逻辑上是不通的。这并不意味着这种组合在故事中不存在；它们确实存在，但讲述者必须为自己的英雄行动提供额外的动机。这里又有一个不合理的连接却被清楚说明动机的例子：伊万与一位老人搏斗。在搏斗过程中，老人无意中让伊万喝下了一剂增益力量的水。这种“无心”之所以可以理解，是因为若把它同那些由感激的或一般而言友好的赠予者赠予饮料的故事相比较，便会恍然大悟。由此我们看到，连接上的不合逻辑，对讲述者而言并不是绊脚石。

如果采取纯粹经验的做法，就会不得不承认，各种 D 与 F 形式在彼此关系上具有完全的可替换性。

下面列出若干连接的具体例子：

**第二类：**

- **D¹ F¹**：一个女巫迫使英雄赶一群母马去放牧。接下来是第二项任务，他完成了，便得到一匹马（160）。
- **D² E² F²**：一位老人盘问英雄。英雄无礼作答，一无所获。后来他返回，恭敬作答，于是得到一匹马（155）。
- **D³ E³ F¹**：一位垂死的父亲请求儿子们在他坟旁守夜三个晚上。最小的儿子完成了请求，得到一匹马（180）。
- **D³ E³ F⁶**：一只小公牛请求沙皇的孩子们把它杀掉、烧掉，把骨灰分种在三条畦里。英雄照办。第一条畦长出一棵苹果树，第二条长出一只狗，第三条长出一匹马（201）。
- **D⁵ F⁵**：兄弟们发现一块大石头。“难道搬不动吗？”（并无考验者的考验。）哥哥们搬不动。最小的搬开石头，露出一座地窖，在窖中伊万找到三匹马（137）。

这一清单可以任意续列。这里只需注意：在类似的情形下，除马之外，也会出现其他魔法赠礼。这里之所以以马为例，是为了更鲜明地勾勒出形态上的亲缘关系。

**第一类：**

- **D⁶ E⁷¹ F⁸**：三个争执者请求分配魔法物品。英雄指示他们互相追逐，趁此时机他自己夺走了那些物品（一顶帽子、一块地毯、一双靴子）。
- **D⁸ E⁸ F⁸**：英雄们落入一个女巫手中。她打算在夜间斩首他们。他们把女巫的女儿们替换到床上，便逃跑了，最小的弟弟顺手带走一条魔法手帕（105）。
- **D¹⁰ E¹⁰ F⁸**：斯马特-拉祖姆，一位隐身精灵，为英雄效力。三位商人提出以一只小箱（一个花园）、一把斧（一条船）和一只号角（一支军队）来交换这位精灵。英雄同意了交换，但事后又召回了他的助手。

我们观察到，在每一类内部，某些方面对另一些方面的大规模替换是确实存在的。另一个问题是：某些被传递的对象是否与某些传递形式相联系（即：是否总是送马，而飞毯总是被夺走，等等）？虽然我们的考察仅就功能本身而言，但仍可以（不列举证据地）指出：并不存在这样的规律。通常是被赠送的马，在第 159 号故事中被夺走；反之，通常被夺走的、能使人逃脱追捕的魔法手帕，在第 159 号及其他故事中却被作为礼物送给英雄。一艘会飞的船，可以被制备、被指示、被赠送，等等。

现在，让我们回到角色功能的列举上来。魔法媒介一经英雄获得，便被投入使用；或者，若所得媒介是生物，英雄便直接下令借助它的帮助。至此，英雄在表面上失去了一切意义：他本人什么也不做，一切都是由他的助手完成的。然而，英雄在形态学上的意义仍然非常大，因为他的意向构成了叙事的轴线。这种意向以英雄向助手发出的各种命令的形式出现。在此处，可以对英雄作出比此前更为精确的界定。**神奇故事的英雄**是这样的人物：他在纠葛之中直接承受加害者的行为（他感到某种匮乏），或者他同意去消除另一个人的不幸或匮乏。在行动进程中，英雄是被赋予一种魔法媒介（魔法助手）的人，是使用它或受其服务的人。

### XV. 英雄被送往、送达或被引领至所寻之物的所在之处
**（定义：两王国之间的空间转换、引导，符号：G）**

通常，所寻之物位于“另一个”或“不同”的王国。这一王国可能在水平方向上相距遥远，也可能位于很高的天上或很深的地下。统一这些情形的方式可以是相同的，但极高与极深各有其特有的形式。

1. **英雄在空中飞行**（G¹）：骑在一匹马上（171）；骑在一只鸟上（219）；以鸟的形态飞行（162）；乘一艘会飞的船（138）；乘一块飞毯（192）；骑在一个巨人或精灵的背上（212）；乘魔鬼的马车（154）；等等。乘鸟飞行有时伴有这样一个细节：在途中必须喂鸟，因此英雄随身带上一头牛等等。

2. **他在地面或水面上行进**（G²）：骑在马或狼的背上（168）；乘一条船（247）；一个无手者背负一个无腿者（198）；一只猫骑在狗的背上渡过河（190）。

3. **他被人引领**（G³）。 一只线团指示路径（234）；一只狐狸把英雄领到公主那里（163）。

4. **道路被指给他看**（G⁴）。 一只刺猬给一位被劫的弟弟指路（113）。

5. **他使用固定的通行手段**（G⁵）。 他爬上一段阶梯（156）；他找到并使用一条地下通道（141）；他骑在一只巨大的梭鱼背上，如过桥一般（156）；他借皮带下坠，等等。

6. **他循着血迹追踪**（G⁶）。 英雄击败一位藏身于石头之下的林中居民，沿其足迹，伊万找到了通往另一个王国的入口。

至此，英雄的各种转移形式已告穷尽。应当指出，“送达”作为一种功能本身有时是缺席的：英雄自己走到那里（即 G 只是 ↑ 的一种自然延续）。在这种情况下，G 并不单列。

### XVI. 英雄与加害者进入正面搏斗
**（定义：搏斗，符号：H）**

这一形式必须与同敌对的赠予者的搏斗（战斗）相区别。这两种形式可以由其结果加以区分。如果英雄为了进一步寻找而获得一种媒介，作为不友好遭遇的结果，那么这就是要素 D。反之，如果英雄通过胜利获得了所寻之物本身，那么这便是 H。

1. **他们在旷野中交战**（H¹）。 首先包括与龙或与齐斗—尤斗等的搏斗（125），还包括与敌军或一位骑士等的战斗（212）。

2. **他们进行比赛**（H²）。 在滑稽故事中，搏斗本身有时并不发生。在一番争吵之后（常常与激战前的争吵完全类似），英雄与加害者举行比赛。英雄凭借机智取胜：一个吉卜赛人假装用力捏碎一块奶酪，如捏石一般；佯装击中后脑勺却不过是吹一声口哨，等等（149）。

3. **他们打牌**（H³）。 英雄与一条龙（一个魔鬼）打牌（192、153）。

4. **第 93 号故事展示了一种特殊形式**：一条雌龙向英雄提议：“让王子伊万同我一起站到秤上；看谁压过谁？”（H⁴）。

### XVII. 英雄被打上印记
**（定义：印记、标记，符号：J）**

1. **印记被施于身体**（J¹）。 英雄在格斗中受伤。一位公主在搏斗前用小刀在他脸颊上划出一道小伤口，从而唤醒了他（125）。 一位公主用一枚图章戒指在英雄额头上打下印记（195）；她吻他，在他额上留下一颗灼热的星。

2. **英雄获得一枚戒指或一条毛巾**（J²）。 若英雄在搏斗中受伤，且伤口被一位公主或一位国王的手帕包扎，则构成两种形式的组合。

### XVIII. 加害者被战胜
**（定义：胜利，符号：I）**

1. 加害者在公开搏斗中被击败（I¹）。
2. 他在比赛中被击败（I²）。
3. 他在牌局中落败（I³）。
4. 他在称重中落败（I⁴）。
5. 他在未经预备搏斗的情况下被杀（I⁵）。 一条龙在睡梦中被杀（141）。 兹米乌尔丹藏身于一棵树的空洞中，被杀（164）。
6. 他被直接驱逐（I⁶）。 一位被魔鬼附身的公主将圣像挂于颈上：“邪灵在一缕青烟中飞走了”（115）。

胜利也以否定形式出现。若有两三位英雄前去作战，其中的一个（一位将军）躲起来，而另一位则获胜（符号：⁻I¹）。

### XIX. 最初的不幸或匮乏被消除
**（符号：K）**

这一功能与加害（A）构成一对。叙事在这一功能中达到顶点。

1. **所寻之物被以武力或机智夺取**（K¹）。 这里英雄有时采用与加害者最初劫夺相同的手法。伊万的坐骑变成一个去乞讨的乞丐。公主给了他们施舍。伊万从灌木丛中冲出，他们抓住她并带走（185）。

   **1a.** 有时夺取由两个人物完成，其中一人命令另一人执行实际的捕抓工作（K¹）。 一匹马踩住一只螯虾，并命令它给他取来一件结婚礼服。一只猫捉住一只老鼠，命令它去取一枚小戒指（190）。

2. **所寻之物由数人同时获得，是其行动的快速交替**（K²）。

   这种行动的分配，是由被劫者一系列连续的失败或逃跑尝试所引发的。七位谢苗夺得一位公主：小偷劫走了她，但她化作天鹅飞走；弓箭手把她射落；另一位则替代狗把她从水中捞回；等等（145）。同样，装着科谢伊之死的蛋的获得，也是如此。一只野兔、一只鸭、一条鱼各自带着蛋跑开、飞走、游走。一只狼、一只渡鸦和一条鱼夺得它（156）。

3. **所寻之物被以引诱的方式获得**（K³）。 这一形式在许多情形下与 K¹ 性质极为接近。英雄借金质物品引诱公主登船，并将她带走（242）。 交换提议形式的引诱可以构成一个特殊子类。一位被挖去双眼的女孩绣了一顶精美的王冠，送给那个心怀恶意的使女。使女为换取王冠而归还了双眼，从而夺回。

4. **所求之物作为先前行动的直接结果而被获得**（K⁴）。 例如，若伊万杀了一条龙，之后又娶了他所解救的公主，那么这里便没有把“获得”作为一种特殊行为；它毋宁是情节发展中的一种阶段、一个环节。公主既不是被劫，也不是被拐，但她仍然被“获得”了。她是作为战斗的结果而被获得的。这种情形下的“获得”是一个逻辑上的环节。它也可以由战斗之外的其他行动所达成。因此，伊万可以凭借一段受指引的旅程而找到一位公主。

5. **所寻之物借助魔法媒介瞬间获得**（K⁵）。 两位青年（从一本魔法书中现身）以旋风般的速度送来一头金角鹿（212）。

6. **魔法媒介的使用克服了贫困**（K⁶）。 一只魔法鸭下金蛋（195）。 自行铺设的魔法桌布和会撒金的马，都属于此类。另一形式的自动桌布出现在梭鱼的意象中：“奉梭鱼之命，并承上帝的祝福，让桌面铺好、饭菜齐备！”（167）。

7. **所寻之物被捕获**（K⁷）。 这一形式典型地适用于农业劫掠。英雄捕获正在偷干草的母马（105）。 他捕获正在偷豌豆的鹤（187）。

8. **对人所施的咒语被解除**（K⁸）。 这一形式是 A¹¹（施咒）的典型对应。解除咒语既可以通过焚烧那张皮，也可以通过一句咒语：“重新作回少女吧！”

9. **被杀者被复活**（K⁹）。 一根发针或一颗死牙被从头上取出（210、202）。 英雄被喷以致命之水和赋予生命之水。  
   **9a.** 正如在“反向夺取”中，一只动物迫使另一只动物行动，这里，一只狼抓住一只渡鸦，并迫使它的母亲取来一些致命之水和一些赋予生命之水（168）。这种以获得水为前提的复活方式，可以单列为一个特殊子类（K¹*）。⁷

10. **囚徒被释放**（K¹⁰）。 一匹马撞开地牢的门，救出伊万（185）。 从形态上说，这一形式与例如释放一个林中精灵毫无共同之处，因为后一种情形建立了感恩和给予魔法媒介的基础；而这里则是消除了最初的不幸。 第 259 号故事展示了一种特殊的释放形式：那里的海王总是把囚徒在午夜拖到岸上。英雄恳求太阳解救他。太阳头两次都迟迟不出来；第三次时，“太阳射出光芒，海王再也无法把他拖回牢中”。

11. **所寻之物的接受有时采取与魔法媒介相同的形式**（即：被作为礼物赠予，其所在被指明，被购买，等等）。 这些情形的符号：KF¹（直接传递），KF²（指明），等等，与前相同。

### XX. 英雄归来
**（定义：归来，符号：↓）**

归来通常采取与出发相同的形式。然而，并不需要在归来之后再附加一项特殊功能，因为归来本身就意味着对空间的克服。这对离家而言并非总是如此：离家之后，会得到一种媒介（一匹马、一只鹰，等等），然后才出现飞行或其他行进形式；而归来则是立即的，并且大体采取与出发相同的形式。有时归来具有逃跑的性质。

### XXI. 英雄被追捕
**（定义：追捕、追逐，符号：Pr）**

1. **追捕者飞追英雄**（Pr¹）。 一条龙追上伊万（160）；一个女巫飞追一个男孩（105）；一群鹅飞追一个女孩（113）。

2. **追捕者索要那个有罪之人**（Pr²）。 这一形式也多半与空中的实际飞行相联系：龙的父亲派出一艘会飞的船。从船上他们呼喊：“[我们要]那个有罪之人，有罪之人！”（125）。

3. **追捕者迅速变形为各种动物等等，以追逐英雄**（Pr³）。 这一形式在若干阶段上仍与飞行相联系：一位魔法师以狼、梭鱼、人和公鸡的形态追逐英雄（249）。

4. **追捕者（龙的妻子等）变成诱人之物，并把自己摆在英雄的路上**（Pr⁴）。 “我要跑到前头，让他的日子难熬；我要变成一片绿草地。在这片绿草地里我要变成一口井，井里游着一只银杯……在那里他们将像罂粟籽一样被撕碎”（136）。 雌龙们变成花园、枕头、井，等等。然而，故事并未告诉我们，她们是如何跑到英雄前头的。

5. **追捕者试图吞掉英雄**（Pr⁵）。 一条雌龙变成一位少女，引诱英雄，然后又变成一头母狮，想要吞掉伊万（155）。 一条雌龙之母张开大口，从天到地（138）。

6. **追捕者试图杀死英雄**（Pr⁶）。 他试图把一颗死牙敲进他的头里（202）。

7. **他试图啃断英雄藏身的那棵树**（Pr⁷）。

### XXII. 英雄从追捕中被解救出来
**（定义：解救，符号：Rs）**

1. **他被带上天空**（有时他被以闪电般的飞驰所救）（Rs¹）。 英雄骑在一匹马上（160）或骑在几只鹅上（108）飞走。

2. **英雄一面奔逃，一面在路上为追捕者设置障碍**（Rs²）。 他抛出一把刷子、一把梳子、一条毛巾。它们化作山林、森林、湖泊。同样，维尔托戈尔（搬山者）和维尔托杜勃（搬橡树者）拔起山岭和橡树，将它们摆在雌龙的路上（93）。

3. **英雄在奔逃中变成使他自己不被识别的物件**（Rs³）。 一位公主把她自己和王子变成一口井和一只舀水的瓢，一座教堂和一位神父（219）。

4. **英雄在奔逃中藏身**（Rs⁴）。 一条河、一棵苹果树和一座炉灶将一个姑娘藏了起来（113）。

5. **英雄被铁匠们所藏匿**（Rs⁵）。 一条雌龙索要那个有罪之人。伊万藏在铁匠们那里，他们抓住龙的舌头，用铁锤敲打她（136）。 第 153 号故事中的一段情节无疑与这一形式相关：士兵们把魔鬼们装进一只背袋，带到铁匠铺里用重锤猛打。

6. **英雄在奔逃中以迅速变形为动物、石头等等而自救**（Rs⁶）。 英雄以马、梅花雀、戒指、种子、猎鹰的形态奔逃（249）。 这种变形本身对此形式至关重要。有时奔逃本身可以省略；这种情形可以视为一个特殊子类。一位姑娘被杀，她的遗骸上长出一座花园。花园被砍倒，又化为石头，等等（127）。

7. **他避开变形雌龙的诱惑**（Rs⁷）。 伊万劈砍花园、井，等等；鲜血从中流出（137）。

8. **他不让自己被吞掉**（Rs⁸）。 伊万驱马跃过雌龙的大口。他认出那头母狮就是那条雌龙，便把她杀死（155）。

9. **他被人从一场未遂的谋害中救出来**（Rs⁹）。 动物们及时从他头上拔出了那颗死牙。

10. **他跳到另一棵树上**（Rs¹⁰）。

许多故事在“从追捕中被救出”这一节拍上结束。英雄回到家，然后，如果他已经赢得一位姑娘，便娶她为妻，等等。然而，事情远非总是如此。故事可能为英雄安排另一场不幸：一位加害者可能再次出现，可能夺走伊万所获得的东西，可能杀死伊万，等等。换言之，一项最初的加害会被重复——有时以与开头相同的形式出现，有时则以对该故事而言全新的形式出现。随着这种情况的发生，一段新的故事便开始了。对于重复的加害，并没有特定的形式（即：我们仍然面对着劫持、咒杀、谋杀等等），但与新的不幸相联系的，却是特定的加害者。他们就是伊万的哥哥们。就在英雄到家之后不久，他们便夺走他的战利品，有时甚至连他也杀掉。如果他们容他活着，那么，为了挑起一场新的寻找，便有必要再次在英雄和所求之物之间设下巨大的空间障碍。这是通过他们把他扔入深渊（坑、地下王国，有时是大海）来实现的，他有时会整整跌落三天。随后一切重新开始：再一次与赠予者偶然相遇；一项顺利完成的重任或所提供的服务，等等；魔法媒介的获得及其被使用，以将英雄送回他自己的王国。从这一刻起，发展过程便与故事开始时不同；我们将在后文讨论它。

这一现象表明，许多故事由两套可以称为“轮次”（ходы）的功能序列所构成。一项新的加害行为造成一个新的“轮次”，如此一来，有时一整批故事便合成一个单一的故事。然而，下面将要描述的发展过程，确实构成既定故事的延续，尽管它同时也创造了一个新的轮次。为此，我们必须最终弄清，每一篇文本中包含的故事究竟有几个。

- **F///bis.** 伊万的兄弟们夺走他的战利品（并把他扔进深渊）。  
  加害已用符号 A 表示。若兄弟们劫走伊万的新娘，则此行为的符号为 A¹。若他们夺走一种魔法媒介，则符号为 A²。劫持伴随谋杀的，称为 A¹⁴¹。与英雄被扔入深渊相联系的形式，将被标记为 *A¹、*A²、*A¹⁴²，等等。

- **X-X/bis.** 英雄再次出发去寻觅某物（C¹）（参见 X—XI）。  
  这一要素有时在此处被省略。伊万四处徘徊并哭泣，仿佛并未考虑归来。要素 B（派遣）在这些情形下也总是缺席，因为没有理由派遣伊万——他是那位新娘被劫走的人。

- **X//bis.** 英雄再次成为导致获得魔法媒介的那些行动的主体（D）（参见 XII）。

- **X/J/bis.** 英雄再次对未来的赠予者的行为作出反应（E）（参见 XIII）。

- **X/F/bis.** 一种新的魔法媒介被置于英雄支配之下（F）（参见 XIV）。

- **XF/bis.** 英雄被带至或运送至所寻之物的所在之处（G）（参见 XV）。在此情形下，他到达了家中。

从这一点起，叙事的发展开始不同；故事给出新的功能。

### XXIII. 英雄在未被识别的情况下抵达家中或另一个国家
**（定义：未被识别的抵达，符号：o）**

在此可以分辨出两类：（1）抵达家中，英雄以某种手艺人的身份（金匠、裁缝、鞋匠等）留下来当学徒；（2）他抵达某位国王的宫廷，作为厨子或马夫效力。同时，有时还需要把单纯的抵达也标注出来。

### XXIV. 一位冒牌的英雄提出虚假的冒功
**（定义：虚假的冒功，符号：L）**

若英雄抵达家中，虚假的冒功由他的兄弟们提出。若他在另一个王国效力，则由一位将军、一名挑水夫或其他人提出。兄弟们装作猎获战利品的人；将军装作屠龙的人。这两种形式可以视为特殊的类。

### XXV. 一项难题被摆到英雄面前
**（定义：难题，符号：M）**

这是故事最喜欢的要素之一。难题也出现在前述连接之外，但这些连接将在稍后讨论。此处暂且就难题本身加以讨论。这些难题极其多样，每一种都需要一个专门的符号。然而眼下无须深入细节。既然不作精确的划分，我们就把我们材料中出现的所有实例一一列出，并大致归组：

- **饮食之试**：吃下一定数量的牛或若干大车的面包；喝下大量啤酒（137、138、144）。
- **烈火之试**：在烧红的铁浴室中洗浴。这一形式总与前一项相联系（137、138、144）。另一种独立形式：在沸水中沐浴（169）。
- **猜谜及类似的考验**：提出一个无解之谜（239）；叙述并解释一个梦（241）；解释乌鸦在沙皇窗前的啼叫之意，并把它们赶走（247）；猜出（或推断出）沙皇女儿的独特标记（238）。
- **辨识之试**：在十二位长相相同的姑娘（或男孩）中选出所要寻找的人（219、227、249）。
- **捉迷藏**：把自己藏起来，使发现成为不可能（236）。
- **在窗口吻公主**（180、182）。
- **跃上门顶**（101）。
- **力量、敏捷、坚忍的考验**：公主在夜间掐住伊万的脖子，或紧握他的手（198、136）；交给英雄的任务是：抬起被斩龙头（171）、驯马（198）、挤一群野马（170）、击败一个女战士（202），或者一个对手（167）。
- **耐力的考验**：在锡国待上七年（270）。
- **供给与制造之任务**：供应一种药（123）；取得一件婚礼礼服、一枚戒指、一双鞋（132、139、156、169）；交出海王的头发（240）；交付一艘会飞的船（144）；交付赋予生命之水（144）；提供一支军队（144）；获得七十七匹母马（170）；一夜之间建起一座宫殿（190），以及通往宫殿的一座桥（216）；带来“给我那未知者的配对物”（240）。
- **作为制造之任务**：缝制衬衣（104、267）；烤面包（267）；作为这类任务的第三项，沙皇询问谁的舞跳得更好。
- **其他任务**：从某一灌木或树上采浆果（100、101）；用一根杆子跨过一道沟（137）；找到“蜡烛会自动点燃的人”（195）。

如何把这些难题与其他与之高度相似的要素相区分，将在关于“同化”的那一章中加以说明。

### XXVI. 难题被解答
**（定义：解答，符号：N）**

解答的形式，自然与难题的形式一一对应。某些任务在被布置之前，或在指定时间之前，便已完成。于是英雄在请求被提出之前就已经弄清公主的独特标记。这种预备性的解答，将以符号 **\*N** 标记。

### XXVII. 英雄被认出
**（定义：相认，符号：Q）**

英雄凭借一道印记、一处标记（一道伤、一颗星形的标记），或凭借所赠之物（一枚戒指、一条毛巾）而被认出。在这一情形下，相认作为一种功能，与印记（J）相对应。英雄还可以凭借完成一项难题而被认出（这一情形几乎总是以“未被识别的抵达”为前导）。最后，英雄可能在长期的分别之后立即被认出。在后一种情形下，父母与子女、兄弟与姐妹等彼此相认。

### XXVIII. 冒牌的英雄或加害者被揭穿
**（定义：揭穿，符号：Ex）**

这一功能在大多数情形下与前一项相联系。有时它是一道未完成的难题的结果（冒牌的英雄抬不起龙头）。最常见的是以“讲故事”的形式呈现——“这时公主把一切都原原本本说了出来”。有时，全部事件以故事的形式，从头至尾被重述。加害者也在听众之中，他因不满之词而自我暴露（197）。有时，有一首歌谣唱出所发生的事，从而揭穿加害者（244）。揭穿的其他独特形式也会出现（258）。

### XXIX. 英雄获得新的外形
**（定义：变形，符号：T）**

1. **新外形由助手的魔法行为直接造成**（T¹）。 英雄穿过马（或牛）的耳朵，获得一副崭新的、英俊的外表。

2. **英雄建起一座非凡的宫殿**（T²）。 他本人作为王子住在宫殿之中。一名少女在夜里忽然在一座非凡的宫殿中醒来（127）。 在这些情形下，英雄虽未必总是被变形，但他的容貌确实发生了变化。

3. **英雄穿上新衣**（T³）。 一位女孩穿上（一件魔法？）衣服和饰物，立刻变得光彩照人，人人惊叹（234）。

4. **理性化与滑稽的形式**（T⁴）。 这些形式部分地可以由前述形式（作为其变形）加以解释，另一部分则必须结合对故事—逸事的研究来说明，因为它们正源于此。在这些情形下，实际的外形变化并未发生，而新的外表是通过欺骗取得的。例如，一只狐狸把库津卡带到一位国王面前，说库津卡掉进了沟里，请求赐予衣服。狐狸得到了王室的服饰。库津卡穿上王室的衣装，便被当作了沙皇的儿子。所有类似的情形都可以用以下方式表述：关于财富与美貌的虚假证据被接受为真实的证据。

### XXX. 加害者受到惩罚
**（定义：惩罚，符号：U）**

加害者被枪决、被流放、被绑在马尾上、被迫自尽，等等。与此并行，我们有时还可以看到宽大的赦免（U 负）。通常只有第二轮的加害者和冒牌的英雄受到惩罚；只有当故事中既无搏斗又无追捕时，第一位加害者才受到惩罚。否则，他便在搏斗中被杀，或在追捕中丧命（女巫试图把海水喝光而胀破，等等）。

### XXXI. 英雄成婚并登上王位
**（定义：成婚，符号：W）**

1. **新娘与王国同时被赐予，或者英雄先获得半壁江山，待父母亡故后再获全部**（W¹）。

2. **有时英雄仅仅成婚而未获得王位，因为他的新娘并非公主**（W⁻）。

3. **有时只提及登基**（W⁰）。

4. **若在成婚之前不久发生一项新的加害而中断故事，那么第一轮以订婚或婚约结束**（w¹）。

5. **与前一种情形相反，一位已婚的英雄失去妻子；婚姻经由一项追寻而得以恢复**（恢复后的婚姻符号：w²）。

6. **有时英雄得到的是一笔金钱奖赏或某种其他形式的补偿，代替公主之手**（w°）。

故事到此便告结束。还应当指出，在个别情形中，存在某些英雄的行为，它们既不符合前述各项功能，也未被这些功能所界定。这种情形很罕见。它们或是一些没有比较材料就无法理解的形式，或是从其他类别的故事（逸事、传说等）中移植过来的形式。我们把这些称为**不明确的要素**，并赋予符号 **X**。

从前面的观察中，可以得出哪些结论呢？首先是若干一般的推论。我们看到，功能的数量其实十分有限。可注意到的功能只有约三十一项。我们材料中所包括的一切故事，其行动都在这三十一项功能的范围之内展开。对于极为不同的民族的许多其他故事，也可以作出同样的论断。进一步，如果我们将所有功能依次通读一遍，便可看到，一种功能以逻辑和艺术上的必然性从另一种功能中发展出来。我们看到，没有一种功能排斥另一种功能。它们都归属同一条轴线，而不是如前所述那样归属于若干条轴线。

现在，我们提出若干虽属个别却极为重要的推论。我们观察到，大量功能都是成对排列的（禁令—违禁，侦察—泄漏，搏斗—胜利，追捕—解救，等等）。其他功能可以按群分组。因此，加害、派遣、决定反制、离家（ABC↑）便构成了纠葛。要素 DEF 也合为某种整体。在这些组合之外，又有若干独立的功能（离家外出、惩罚、成婚，等等）。我们此刻仅记下这些个别的推论。功能成对排列这一观察，以及此处得出的一般推论，对后文都同样有用。

在这一点上，我们必须近距离地审视故事的个别文本。这一图式如何适用于这些文本，以及个别故事相对于这一图式构成什么，这些问题只有通过对文本的分析才能得到解答。反过来，“这一图式相对于这些故事又意味着什么？”这一问题，则可以现在就作答。这一图式，乃衡量个别故事的一把尺。正如布料可以用尺来量其长度，故事也可以用这一图式加以衡量，由此得到界定。将这一图式应用于不同的故事，还可以界定故事彼此之间的关系。我们已经可以预见，故事情节的亲缘性问题、情节与异文的问题，借此或可获得一种新的解决。
