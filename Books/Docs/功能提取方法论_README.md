# 故事形态学：功能提取方法论（基于普罗普原文）

> **理论来源**：弗拉基米尔·雅可夫列维奇·普罗普（V. Propp）《民间故事形态学》第二版（1928/1958）
>
> **适用范围**：神话、传说、民间故事、小说、影视剧本等任何可识别其"功能序列"的叙事文本
>
> **方法论定位**：本文档严格按照普罗普原文的核心立场重写，以**功能关系**为分析核心，**功能与角色严格分离**，**辅助要素独立成类**

---

## 普罗普原文的核心立场

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │

## 一、核心概念

### 1.1 功能（Function）

**定义**：角色的一个动作，从它对行动进程的意义出发来加以界定。

**判断原则**（普罗普第二章原文）：
- **不以执行者为转移**：龙劫走公主与魔鬼劫走公主是同一功能
- **以动作为依据**：用表示动作的名词形式表达（禁令、违禁、追捕……）
- **必须考虑位置**：同样的行为在不同位置上意义不同
  - 例 1：伊万娶沙皇女儿 ≠ 父亲娶带着两个女儿的寡妇
  - 例 2：父亲给伊万一百卢布买猫 ≠ 国王因英勇行为赏钱

> **关键原则**：普罗普原文："**功能必须独立于实现功能的方式及手段来界定**。"

**分析模板**：

```
┌─────────────────────────────────────────────────────────────┐
│  功能提取分析                                              │
│                                                              │
│  原文：______________________________                       │
│                                                              │
│  第一步：找谓语（动词）                                      │
│  动作/行为：_________________________                       │
│                                                              │
│  第二步：界定功能（从对行动进程的意义出发）                  │
│  功能符号：______  功能名称：______                          │
│                                                              │
│  第三步：标注实现形式（下标，仅记录不分类）                  │
│  品种下标：______  实现方式：________________               │
│                                                              │
│  第四步：判定位置（这是第几个功能）                          │
│  图式位置：第___个功能                                      │
│  前一个功能：______  后一个功能：______                      │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 轮次（Move / ход）

**定义**：从**起点**到**终点**的完整发展过程。

**普罗普原文（第八章A节）**：
> "一项新的加害行为、每一项新的匮乏，都造成一个新的轮次。"

**公式**：

```
┌─────────────────────────────────────────────────────────────┐
│  轮次 = 起点（∅/a/A） → 中介功能群 → 终点（W*/K*/Rs/T*)  │
│                                                              │
│  起点类型：                                                  │
│  ├─ ∅ = 从初始情境直接开始（无加害/匮乏）                  │
│  ├─ a = 从匮乏/缺失开始                                    │
│  └─ A = 从加害开始                                          │
│                                                              │
│  终点类型：                                                  │
│  ├─ W* = 婚姻/成婚                                         │
│  ├─ K* = 缺失被消除                                        │
│  ├─ Rs = 从追捕中逃脱                                      │
│  └─ T* = 变形/转化为新形态                                 │
│                                                              │
│  关键原则：每一项新的加害或匮乏造成一个新的轮次              │
│  一个故事可包含若干轮次，轮次可交织                          │
└─────────────────────────────────────────────────────────────┘
```

**轮次关系**（普罗普原文第八章A节）：

```
┌─────────────────────────────────────────────────────────────┐
│  轮次的六种结合方式                                          │
│                                                              │
│  1. 直接接续：一个轮次结束后开始下一个                      │
│  2. 相互交织：一轮次中断，插入另一轮次，再恢复              │
│  3. 多层嵌套：插曲本身又被另一插曲打断                      │
│  4. 共同开始：两个轮次同时由两项加害引发                    │
│  5. 共同结局：两个轮次共享一个结局                          │
│  6. 路标分别：两个英雄在路标处分开（符号 <）                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 角色（Dramatis Personae）

**定义**：承担一个或多个功能的具体行动者。

**普罗普原文原则**（第二章）：
> "功能的数量极其有限，而角色的数量则极其庞大。"

**七大角色**（普罗普第六章）：

| 角色 | 核心行动圈 |
|------|------------|
| **加害者**（villain） | A（加害）、H（搏斗）、Pr（追捕） |
| **赠予者**（donor） | D（准备）、F（媒介提供） |
| **助手**（helper） | G（转移）、K（消除）、Rs（解救）、N（解答）、T（变形） |
| **公主及其父王**（princess/father） | M（难题）、J（印记）、Ex（揭穿）、Q（相认）、U（惩罚）、W（成婚） |
| **派遣者**（dispatcher） | B（衔接环节） |
| **英雄**（hero） | C（反制决定）、E（对考验的反应）、W*（成婚） |
| **冒牌英雄**（false hero） | L（冒功）、E（对考验的反应）、C↑ |

**关键原则**（普罗普第六章）：
- 角色按**行动圈**分类，不按功能品种
- 一个角色可同时介入若干行动圈（如"父亲"既是派遣者又是赠予者）
- 一个行动圈可分配给若干角色（如"加害者"由龙、龙妻、龙女共同承担）
- **角色命名与属性完全自由**（普罗普第八章D节原文）

### 1.4 辅助要素（Auxiliary Elements）

**普罗普原文（第五章）将辅助要素分为三类**：

```
┌─────────────────────────────────────────────────────────────┐
│  辅助要素：连接、重复、解释的三种独立维度                    │
│                                                              │
│  类型1：衔接要素（connectives）    符号 §                     │
│  ├─ 通报（announcements）：公主派小狗送信                      │
│  ├─ 对话（dialogues）：女巫与伊万的对话                     │
│  ├─ 看到（sightings）：沙皇看到对面的宫殿                  │
│  ├─ 被带来（being brought）：老人给沙皇带来一只鸟          │
│  └─ 设宴（feasts）：设宴连接 N 与 Q                        │
│                                                              │
│  类型2：三重化要素（trebling elements）  符号 :              │
│  ├─ 均匀分布（uniform）：三个任务、三年服役                │
│  ├─ 递进（progressive）：第三个任务最艰巨                   │
│  └─ 否定-成功（negative-positive）：前两次失败、第三次成功 │
│                                                              │
│  类型3：动机（motivations）                                  │
│  ├─ 驱动加害的动机：嫉妒、贪婪、怨恨                       │
│  ├─ 驱动派遣的动机：父母祝福、沙皇许诺                     │
│  └─ 驱动寻找的动机：被美貌吸引、被欲望驱动                 │
│                                                              │
│  关键：这些不是功能，但可使故事更丰富                        │
│  普罗普原文："动机属于故事中最易变化、最不稳定的要素"       │
└─────────────────────────────────────────────────────────────┘
```

## 二、品种（Variants）：普罗普原文的真实分类法

### 2.1 普罗普论品种的真实立场

```
┌─────────────────────────────────────────────────────────────┐
│  普罗普论品种的原文原则（综合二三章）                        │
│                                                              │
│  1. 品种是"功能实现的方式"，不是独立分类                   │
│     └─ 原文（第三章）："功能的实现形式可以变化"            │
│                                                              │
│  2. 品种应当"不必将所有实例系统化"                         │
│     └─ 原文（第三章）："只需择取最关紧要的几类，            │
│        其余概括处理即可"                                    │
│                                                              │
│  3. 品种的下标维度是混合的（不是统一维度）                  │
│     └─ 普罗普原文中 A¹ 按"对象"分，A⁶ 按"动作烈度"分    │
│     └─ A¹⁸ 按"时间"分，A¹⁹ 按"对象"分                   │
│     └─ 普罗普本人就承认："分离出几种最重要的形式"          │
│                                                              │
│  4. 角色不进入功能下标                                      │
│     └─ 普罗普原文："功能界定绝不能以执行功能的角色为转移" │
│     └─ 角色应在独立章节中按"行动圈"分析                   │
│                                                              │
│  5. 文化背景不进入功能下标                                  │
│     └─ 普罗普原文："一切神奇故事在结构上属于同一个类型"   │
│     └─ 文化差异通过角色实例和属性体现                      │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 普罗普原文下标的多维混合（基于第三章原文）

下标本质上是"实现方式"的标记，普罗普在原文中实际使用了多种维度：

| 维度 | 说明 | 普罗普示例 |
|------|------|------------|
| **对象类型** | 动作指向的对象 | A¹（人）/ A²（魔法物品）/ A³（庄稼） |
| **动作类型** | 动作本身的细分 | A⁶（身体伤害）/ A⁹（驱逐）/ A¹¹（施咒） |
| **执行方式** | 动作如何被执行 | A¹³（命令）/ A¹⁴（亲手） |
| **动作目的** | 动作要达到什么 | A¹⁶（强迫婚姻）/ A¹⁷（食人威胁） |
| **动作环境** | 动作发生的时间地点 | A¹⁸（夜间施虐） |

> **方法论要点**：下标维度不需要统一。每个下标表达一种重要的实现方式即可。普罗普本人就是这么做的。

### 2.3 品种分析的正确位置

```
┌─────────────────────────────────────────────────────────────┐
│  普罗普第八章B节（《天鹅鹅》分析）的真实做法                │
│                                                              │
│  在逐句分析时，"品种"应当作为**备注项**而非独立分类：      │
│                                                              │
│  句子序号 | 原文 | 功能 | 实现形式 | 备注（角色/关系/变异）│
│  ─────────────────────────────────────────────────────────  │
│  1       | ...  | α    | 无       | 角色：老头儿、老太婆   │
│  2       | ...  | γ¹   | 直接禁令 | 角色：母亲             │
│  3       | ...  | β¹   | 父母外出 | 角色：父母             │
│  4       | ...  | δ¹   | 违禁     | 同上                   │
│  5       | ...  | A¹   | 拐人     | 角色：天鹅鹅           │
│  ...     | ...  | ...  | ...      | ...                    │
│                                                              │
│  关键：                                                       │
│  ├─ 品种下标简短标注即可，不必"严格系统化"                │
│  ├─ 角色在备注栏独立记录                                  │
│  ├─ 功能对关系在备注栏标注                                │
│  └─ 变异类型在备注栏标注                                  │
└─────────────────────────────────────────────────────────────┘
```

## 三、31项功能的标准列表（基于普罗普第三章原文）

### 3.1 准备部分（Prep Functions）

| 符号 | 名称 | 普罗普原文说明 | 品种下标 |
|------|------|----------------|----------|
| **α** | 初始情境 | 家庭成员被一一列出，或英雄通过姓名引入 | 无 |
| **β** | 离家外出 | 一名家庭成员离家 | β¹ 上代 / β² 亡故强化 / β³ 下代 |
| **γ** | 禁令 | 对英雄施加一道禁令 | γ¹ 直接禁令 / γ² 颠倒形式（命令） |
| **δ** | 违禁 | 禁令被违犯 | δ¹ 违禁 / δ⁻ 违禁强化 |
| **ε** | 侦察 | 加害者试图侦察 | ε¹ 直接询问 / ε² 颠倒（受害者发问） / ε³ 通过他人 |
| **ζ** | 泄漏 | 加害者获得信息 | ζ¹ 直接得到答复 / ζ²-ζ³ 颠倒回答 |
| **η** | 欺骗 | 加害者欺骗受害者 | η¹ 劝说 / η² 直接动用魔法 / η³ 其他欺骗或强制 |
| **θ** | 顺从 | 受害者顺从欺骗 | θ¹ 接受劝说 / θ²-θ³ 机械反应 |

### 3.2 复杂部分（Complication Functions）

| 符号 | 名称 | 普罗普原文说明 | 品种下标 |
|------|------|----------------|----------|
| **A** | 加害 | 加害者造成损害或伤害 | 见下表 |
| **a** | 匮乏 | 家中成员缺少某物或渴望某物 | a¹ 缺新娘 / a² 需魔法媒介 / a³ 缺奇物 / a⁴ 特殊形式 / a⁵ 理性化 / a⁶ 其他 |

**A（加害）的19种实现形式**（普罗普原文第三章，严格按原文）：

| 下标 | 名称 | 普罗普原文说明 |
|------|------|----------------|
| A¹ | 绑架人 | 龙劫走公主、哥哥劫走新娘 |
| A² | 夺取魔法媒介 | "不起眼的家伙"夺走魔法小匣、公主夺走魔法衬衣 |
| A²ᵃ | 对魔法助手的强行劫夺 | 继母宰杀奇迹奶牛、文书宰杀魔法鸭 |
| A³ | 劫掠或糟蹋庄稼 | 马吃光干草、熊偷走燕麦、鹤偷走豌豆 |
| A⁴ | 夺走日光 | （罕见） |
| A⁵ | 其他形式劫掠 | 火鸟偷金苹果、鼬兽叼走动物 |
| A⁶ | 造成身体伤害 | 挖出双眼、砍掉双腿 |
| A⁷ | 造成突然的消失 | 沉睡后新娘永远消失、骑飞毯离开 |
| A⁸ | 索取或诱拐受害者 | 海王要求得到沙皇儿子 |
| A⁹ | 驱逐 | 继母把继女赶出家门 |
| A¹⁰ | 命令抛入海中 | 沙皇把女儿女婿放进木桶抛入大海 |
| A¹¹ | 施咒 | 妻子把丈夫变成狗、继母把继女变成猞猁 |
| A¹² | 替换 | 奶妈把新娘变成鸭子、自己女儿顶替 |
| A¹³ | 命令杀人 | 继母命令仆人杀掉继女 |
| A¹⁴ | 亲手杀人 | 公主夺走魔法衬衣后杀死丈夫 |
| A¹⁵ | 监禁或扣押 | 公主把伊万关入地牢 |
| A¹⁶ | 强迫婚姻威胁 | 龙要求把公主许配给自己 |
| A¹⁶ᵃ | 亲属间强迫婚姻 | 哥哥要娶妹妹 |
| A¹⁷ | 食人威胁 | 龙要求把公主给自己当晚餐 |
| A¹⁷ᵃ | 亲属间食人 | 姐姐要吃弟弟 |
| A¹⁸ | 夜间施虐 | 龙/魔鬼夜间虐待公主 |
| A¹⁹ | 宣战 | 邻近沙皇宣战、龙蹂躏诸国 |

> **重要原则**（普罗普原文）："劫夺的对象并不影响行动的进程……更恰当的做法是将一切劫夺视为加害的同一种形式，而把其具体形态视为子类而非类。" 这是下标存在"多维混合"的根本原因。

### 3.4 搏斗与胜利部分（Combat Functions）

| 符号 | 名称 | 普罗普原文说明 | 品种下标 |
|------|------|----------------|----------|

## 四、功能与角色的严格分离（核心原则）

### 4.1 普罗普原文的明确立场

```
┌─────────────────────────────────────────────────────────────┐
│  普罗普原文（第二章）                                        │
│                                                              │
│  "角色常常把同样的行为赋予不同的角色。"                    │
│  "故事常常把同样的行为赋予不同的角色。"                    │
│  "芭芭雅嘎、严寒老人、熊、林中精灵、马头，                 │
│   都会考验继女并给予奖赏。"                                │
│  "严寒老人的行事方式与芭芭雅嘎不同。                        │
│   但功能本身是常项。"                                       │
│                                                              │
│  结论：                                                       │
│  ├─ 功能是"做什么"（谓语）                                │
│  ├─ 角色是"谁做"（主语）                                  │
│  └─ 二者必须严格分离                                       │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 分离操作的具体规则

```
┌─────────────────────────────────────────────────────────────┐
│  功能与角色分离的操作规则                                    │
│                                                              │
│  规则1：功能下标不标注角色                                  │
│  ├─ A¹ = 拐人（不写"龙拐人"或"继母拐人"）                │
│  ├─ 角色在备注栏独立记录                                   │
│  └─ 同一下标可对应不同角色                                 │
│                                                              │
│  规则2：角色分类按"行动圈"                                  │
│  ├─ villain_行动圈 = A + H + Pr                            │
│  ├─ donor_行动圈 = D + F                                   │
│  ├─ helper_行动圈 = G + K + Rs + N + T                     │
│  ├─ princess_行动圈 = M + J + Ex + Q + U + W              │
│  ├─ dispatcher_行动圈 = B                                   │
│  ├─ hero_行动圈 = C + E + W*                              │
│  └─ false_hero_行动圈 = L + E + C↑                        │
│                                                              │
│  规则3：角色可同时介入若干行动圈                            │
│  ├─ 例1：小铁人（既是赠予者又是助手）                     │
│  ├─ 例2：父亲（既是派遣者又是赠予者）                     │
│  ├─ 例3：女巫（加害者+非自愿助手）                         │
│  └─ 例4：智慧妻子（赠予者+助手+公主）                     │
│                                                              │
│  规则4：行动圈可分配给若干角色                              │
│  ├─ 例：龙被杀后，追捕由龙妻、龙女承担                    │
│  └─ 例：赠予者考验后，由其他角色给出奖赏                  │
└─────────────────────────────────────────────────────────────┘
```

### 4.2.5 角色的融合、复制与变形（普罗普第七章原文）

```
┌─────────────────────────────────────────────────────────────┐
│  角色在故事中的复合现象（独立于功能分析）                    │
│                                                              │
│  1. 角色融合（fusion）                                        │
│     ├─ 多个角色由同一个人承担                                │
│     ├─ 例：女巫 = 赠予者 + 加害者                            │
│     ├─ 例：父王 = 派遣者 + 赠予者                            │
│     ├─ 例：智慧妻子 = 赠予者 + 助手 + 公主                  │
│     └─ 例：林中小屋的老人 = 赠予者 + 助手                   │
│                                                              │
│  2. 角色复制（doubling）                                     │
│     ├─ 同一行动圈由若干角色分担                              │
│     ├─ 例：龙 + 龙妻 + 龙女共同构成加害者行动圈             │
│     ├─ 例：三个兄弟共同构成英雄-冒牌英雄行动圈             │
│     └─ 例：女巫的姐妹们各自承担一部分助手功能              │
│                                                              │
│  3. 角色变形（transformation）                                │
│     ├─ 加害者有时变形为另一种形象出场                        │
│     ├─ 例：天鹅鹅本是公主/被劫之人                           │
│     ├─ 例：火鸟既能加害又同时承担赠予者功能                 │
│     └─ 注意：变形不改变功能分类，只改变实现形式            │
│                                                              │
│  关键原则：                                                   │
│  ├─ 角色融合、复制、变形都属于"角色层"的现象                │
│  ├─ 不进入功能下标，仅在备注栏标注                          │
│  ├─ 普罗普原文：这是角色分类的"灵活性"，而非"混乱"        │
│  └─ 角色命名完全自由（第八章D节原文）                       │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 七角色行动圈表（基于普罗普第六章原文）

## 五、功能关系（普罗普真正研究的"系统化"对象）

### 5.1 普罗普原文论功能关系的核心地位

```
┌─────────────────────────────────────────────────────────────┐
│  普罗普原文（第八章D节）                                    │
│                                                              │
│  "一种功能的若干品种，是否必然与另一种功能的相应品种相联系？"│
│                                                              │
│  普罗普的明确结论：                                          │
│                                                              │
│  1. 存在必然配对关系                                         │
│     "有些要素毫无例外地总是与彼此相对应的品种相联系"        │
│     例：H¹ 必然配 I¹（旷野搏斗必然配旷野胜利）             │
│     例：禁令必然配违禁                                       │
│     例：欺骗必然配顺从                                       │
│                                                              │
│  2. 存在相对依赖关系                                         │
│     "某些依赖关系的规范，虽然本身显而易见，却有时被违反"   │
│     例：劫持可以与反劫持 K¹ 相连、与 K² 相连、与 K⁵ 相连  │
│     例：投梳子总与直接追捕相连，但直接追捕不必总配投梳子   │
│                                                              │
│  3. 存在自由组合关系                                         │
│     "其余一切要素都可以自由地相互连接"                     │
│     例：劫持人之后不必强制要求循血追踪                      │
│     例：施咒不必配呼唤                                       │
│                                                              │
│  关键论断（普罗普原文）：                                    │
│  "对若干要素之间联系的研究，                                  │
│   远比对单个要素的研究更为重要"                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 必然配对关系清单

| 功能对 | 必然关系 | 普罗普原文说明 |
|--------|----------|----------------|
| **γ—δ** | 必然成对 | 禁令必然配违禁 |
| **ε—ζ** | 必然成对 | 侦察必然配获得信息 |
| **η—θ** | 必然成对 | 欺骗必然配顺从 |
| **H—I** | 必然成对（在战斗对中） | 搏斗必然配胜利 |
| **A—K** | 部分必然 | 加害者某些形式必然配消除的某些形式 |
| **A¹¹—K⁸** | 必然成对 | 施咒必然配解咒 |
| **A¹⁴—K⁹** | 必然成对 | 凶杀必然配复活 |
| **Pr⁵—Rs⁸** | 必然成对 | 试图吞掉必然配不被吞 |
| **J—Q** | 必然成对 | 印记必然配相认（通过印记的相认） |
| **M—N** | 必然成对 | 难题必然配解答 |
| **L—Ex** | 必然成对 | 冒功必然配揭穿 |
| **A—U** | 部分必然 | 第二轮加害者必然受惩罚 |

**普罗普原文（第八章D节）**：
> "H¹ 必然与 I¹ 相连；而与 I³ 的联系则是完全不可能且毫无意义的。"
> "禁令与其违禁；试图探知某事与信息的传递；加害者的欺骗与英雄对它的反应；搏斗与胜利；印记与相认——这些功能的所有品种，都彼此永久地相连。"

### 5.3 相对依赖关系（部分品种的稳定联系）

| 主功能 | 依赖的对应功能 | 关系说明 |
|--------|----------------|----------|
| A（劫持） | K¹（反劫持）/ K²（数人夺得）/ K⁵（瞬间获得） | A可与多种K形式配对 |
| A²（夺媒介） | K⁸（解咒）/ K⁹（复活）等 | 取决于A²的具体类型 |
| Pr（追捕） | Rs（解救）：多种形式 | Pr形式决定Rs形式 |
| F（获得） | D（准备）：多种形式 | D-F之间的可替换性极广 |
| G¹（飞行） | 多种传递形式 | G¹可以配各种F和G的组合 |
| **Pr⁵（吞食）** | **Rs⁸（不被吞）** | **必然配对** |
| **投梳子（Rs²子型）** | **直接追捕（Pr⁶）** | 单向必然 |

**普罗普原文重要观察**：
> "在一对之中，一项功能常常可以引出若干种反应，但每一种反应只与那一种引出它的具体形式相绑定。于是，'投下梳子'总与'直接追捕'相连，而'直接追捕'则并非总与'投下梳子'相连。"

### 5.4 自由组合关系

```
┌─────────────────────────────────────────────────────────────┐
│  普罗普原文论自由组合                                        │
│                                                              │
│  "其余一切要素，包括那些实际成对的要素，                    │
│   都可以自由地相互连接，而不违背逻辑或艺术的价值"          │
│                                                              │
│  自由组合的典型例子：                                        │
│  ├─ 劫持人之后可以配循血追踪、飞行追捕、追捕变形          │
│  ├─ 施咒之后可以配呼唤、欺骗、派遣                          │
│  └─ 大多数功能之间的连接是自由的                            │
│                                                              │
│  普罗普原文论民间对自由的利用：                              │
│  "人们对这种自由利用得并不多。                                │
│   例如，没有任何故事把'施咒'与'呼唤'相连，                  │
│   尽管这一连接在艺术上和逻辑上完全可能。"                  │
└─────────────────────────────────────────────────────────────┘
```

### 5.5 倒置关系（第八章D节）

**普罗普原文**：
> "若干功能可以互换位置。"

**主要倒置类型**：

```
┌─────────────────────────────────────────────────────────────┐
│  三种主要倒置                                                │
│                                                              │
│  1. DEF 在 A 之前（倒置序列）                              │
│     └─ 普通故事：先不幸 → 后获得助手                        │
│     └─ 倒置故事：先获得助手 → 后不幸                        │
│                                                              │
│  2. ↑ 在 B 之前                                              │
│     └─ 普通故事：先派遣 → 后出发                            │
│     └─ 倒置故事：先无目的地出发 → 后得知不幸               │
│                                                              │
│  3. H 在 Pr 之后（部分故事）                                │
│     └─ 普通故事：先搏斗 → 后追捕                            │
│     └─ 倒置故事：93号、159号 → 先追捕 → 后搏斗             │
│                                                              │
│  关键原则：                                                   │
│  倒置"不破坏规律"，因为它是"另一种序列"，                  │
│  不是"对规律的破坏"。                                       │
└─────────────────────────────────────────────────────────────┘
```

### 5.6 省略与残迹（omission & vestige，第八章A节）

```
┌─────────────────────────────────────────────────────────────┐
│  功能缺失的几种情形                                          │
│                                                              │
│  1. 完全省略（complete omission）                            │
│     ├─ 整个功能在故事中消失                                  │
│     ├─ 例：英雄回家后不再出现难题（M），直接成婚            │
│     └─ 故事走向变得简单，但仍合法                            │
│                                                              │
│  2. 部分省略（partial omission）                              │
│     ├─ 某一品种在该故事中不出现                              │
│     ├─ 例：英雄的赠予者不出现（D缺失，但F仍由他人给）     │
│     └─ 例：加害者被直接杀死，不经搏斗（I⁵）                │
│                                                              │
│  3. 残迹（vestige / Rudiment）                              │
│     ├─ 功能虽被省略，但其"痕迹"仍残留在叙事中              │
│     ├─ 例：禁令已被省略，但违禁动作仍出现 → 残迹            │
│     ├─ 例：难题已被省略，但还残留"试炼"动作 → 残迹          │
│     └─ 残迹是判定"省略"还是"另一种序列"的关键              │
│                                                              │
│  关键原则（普罗普原文）：                                    │
│  ├─ 残迹比完全省略更常见                                      │
│  ├─ 残迹表明该功能在演化中被保留为叙事元素                  │
│  └─ 残迹不等于功能本身——它是功能缺席时的"影子"            │
└─────────────────────────────────────────────────────────────┘
```

## 六、按"后果"界定功能（同化原则，第四章）

### 6.1 同化原则的核心

**普罗普原文（第四章）**：
> "不同的功能可以以完全相同的方式被实现。我们在这里面对的是某些形式对另一些形式的影响。这种现象可以称为功能的实现方式的同化。"

> "如果完成一项任务之后接着获得了一种魔法媒介，那就是赠予者对英雄的考验（D¹）。如果接着获得的是新娘并随之成婚，那我们面对的就是难题（M）。"

### 6.2 同化的三种主要情形

```
┌─────────────────────────────────────────────────────────────┐
│  同化情形1：选人（形式相同，后果不同）                      │
│                                                              │
│  形式：从一群外观相同的小马/姑娘中选出正确的              │
│                                                              │
│  后果分支：                                                  │
│  ├─ 选马（获得魔法媒介）→ D¹（考验）                      │
│  └─ 选新娘（获得所求之人）→ M（难题）                      │
│                                                              │
│  判别准则："按功能的后果来界定功能"                        │
│                                                              │
│  类型2：难题与搏斗的同化                                     │
│  ├─ 屠龙作为婚姻代价：表面是 H，实际是 M                   │
│  └─ 依据：其后是否随之出现婚姻                              │
│                                                              │
│  类型3：加害与追捕的同化                                     │
│  ├─ 姐姐试图吞食弟弟：从家中逃出 → 故事展开               │
│  ├─ 表面是 A（加害），实际是 A¹⁷¹（被吞）                  │
│  └─ 追逐被移置到故事开头                                    │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 同化的操作含义

```
┌─────────────────────────────────────────────────────────────┐
│  同化原则的操作含义                                          │
│                                                              │
│  1. 不能仅凭"形式"判定功能，必须看"后果"                  │
│  2. 同一形式在不同故事中可能对应不同功能                    │
│  3. 一个动作可能同时具有双重功能                            │
│     └─ 例：公主离开家门 = 违禁（δ¹）+ 顺从欺骗（θ¹）    │
│     └─ 例：故事180中的难题 = 难题（M）+ 呼唤（B¹）       │
│                                                              │
│  普罗普原文：                                                │
│  "某一形式被移置到不同的位置，获得新的意义，                │
│   或者同时保留旧的意义。所有这些现象使分析变得复杂。"      │
└─────────────────────────────────────────────────────────────┘
```

## 七、辅助要素的独立分类（基于普罗普第五章）

### 7.1 衔接要素 §（普罗普原文第五章A节）

```
┌─────────────────────────────────────────────────────────────┐
│  衔接要素：连接功能的辅助手段（不构成独立功能）              │
│                                                              │
│  类型1：通报（announcements）                                │
│  ├─ 直接通报：K 与 Pr 之间（科谢伊之马的话语）             │
│  ├─ 间接通报：派出小狗送信、加害者偷听                      │
│  ├─ 怨言与诽谤：引出派遣                                    │
│  └─ 故事中的对话：赠予者必须先了解情况                      │
│                                                              │
│  类型2：看到（sightings）                                    │
│  ├─ 伊万在沙皇宫殿对面建宫殿 → 沙皇看见 → 嫁女            │
│  ├─ 用望远镜（道具）                                        │
│  └─ "耳聪"与"眼利"角色                                     │
│                                                              │
│  类型3：被带来（being brought）                              │
│  ├─ 老人给沙皇带来鸟                                        │
│  ├─ 牧人为王后带来王冠                                      │
│  └─ 弓箭手带来火鸟羽毛                                      │
│                                                              │
│  类型4：设宴（feasts）                                       │
│  ├─ 公主在宾客间周巡 → 相认                                │
│  └─ 设宴连接 N 与 Q，连接 L 与 Q                            │
│                                                              │
│  类型5：其他衔接                                             │
│  ├─ 抵达婚礼（连接 L 与 Q）                                │
│  └─ 军事检阅（连接 N 与 Ex）                               │
│                                                              │
│  符号：§                                                     │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 三重化要素 :（普罗普原文第五章B节）

```
┌─────────────────────────────────────────────────────────────┐
│  三重化：使相同动作重复的辅助手段                            │
│                                                              │
│  普罗普原文：                                                │
│  "三重化可以出现在个别具有属性性质的细节上                  │
│  （一条龙的三个头），也可以出现在个别功能、                 │
│  成对的功能（追捕—解救）、若干功能群                       │
│  以及整个轮次之上。"                                        │
│                                                              │
│  三种重复模式：                                              │
│                                                              │
│  1. 均匀分布（uniform）                                     │
│     ├─ 三个任务（强度相同）                                 │
│     └─ 三年服役（时间相同）                                 │
│                                                              │
│  2. 递进（progressive）                                     │
│     ├─ 第三个任务最艰巨                                     │
│     └─ 第三场战斗最激烈                                     │
│                                                              │
│  3. 否定-成功（negative-positive）                          │
│     ├─ 前两次尝试失败                                       │
│     └─ 第三次尝试成功                                       │
│                                                              │
│  三重化的辅助要素（不属于功能）：                            │
│  ├─ 木棒试用（折断/不折）→ 不是F，是三重化准备            │
│  ├─ 线团指引（女巫姐妹之间）→ 既是三重化又是G³            │
│  ├─ "咬穿"森林（追捕重复）→ 不是功能，是衔接             │
│  └─ 回到厨房（重复战斗之间）→ 不是↓，是衔接              │
│                                                              │
│  符号：:                                                     │
└─────────────────────────────────────────────────────────────┘
```

### 7.3 动机（普罗普原文第五章C节）

```
┌─────────────────────────────────────────────────────────────┐
│  动机：角色行为的理由与目的（最易变化、最不稳定的要素）    │
│                                                              │
│  普罗普原文：                                                │
│  "动机属于故事中最易变化、最不稳定的要素"                  │
│  "动机从总体上看是外加于故事的"                            │
│                                                              │
│  动机的类型：                                                │
│                                                              │
│  类型1：加害的动机                                          │
│  ├─ 嫉妒、贪婪、怨恨（最常见）                             │
│  ├─ 兄弟因遗产争吵                                         │
│  ├─ 对不贞婚姻的猜疑                                        │
│  └─ 龙与魔鬼的动机通常不被说明                              │
│                                                              │
│  类型2：派遣的动机                                          │
│  ├─ 父母祝福（友善派遣）                                    │
│  ├─ 沙皇许诺（带许诺的呼唤）                                │
│  ├─ 父亲生病（出于孝顺）                                    │
│  ├─ 想摆脱（敌对派遣）                                      │
│  └─ 父亲梦见奇物（渴望型派遣）                              │
│                                                              │
│  类型3：寻找的动机                                          │
│  ├─ 被美貌吸引（火鸟留下的羽毛）                            │
│  ├─ 被欲望驱动（士兵见到公主）                              │
│  ├─ 沙皇梦见奇物                                            │
│  ├─ 想象出来的需要（被利用为借口）                          │
│  └─ 没有明确动机（直接派遣）                                │
│                                                              │
│  关键原则：                                                   │
│  ├─ 动机不影响功能结构                                      │
│  ├─ 同样的行为可由最不同方式驱动                            │
│  └─ 敌对派遣与友善派遣按相同方式展开                        │
└─────────────────────────────────────────────────────────────┘
```

### 7.4 动机与功能的关联（普罗普原文第五章C节补充）

```
┌─────────────────────────────────────────────────────────────┐
│  动机虽易变，但动机类型与功能形式存在稳定关联                │
│  （这是分析辅助要素时的实用补充）                            │
│                                                              │
│  1. 加害动机 → 加害形式                                      │
│     ├─ 嫉妒/贪婪 → A¹（劫人）/ A²（夺媒介）                │
│     ├─ 复仇 → A⁶（身体伤害）/ A⁹（驱逐）                  │
│     ├─ 政治动机 → A⁹（驱逐）/ A¹²（替换）                  │
│     └─ 魔法动机 → A¹¹（施咒）                              │
│                                                              │
│  2. 派遣动机 → 派遣形式                                      │
│     ├─ 友善派遣（父母祝福） → B¹（呼唤）                   │
│     ├─ 任务派遣（带许诺） → B²（直接派遣）                 │
│     ├─ 驱逐派遣（敌意） → B⁵（驱逐后被带离）              │
│     └─ 渴望派遣（父亲梦见） → B⁴（宣布不幸）              │
│                                                              │
│  3. 寻找动机 → 寻找形式                                      │
│     ├─ 被美貌吸引 → C↑（出发寻找）                          │
│     ├─ 被欲望驱动 → C↑                                      │
│     └─ 复仇驱动 → C↑（追踪）                                │
│                                                              │
│  关键原则：                                                   │
│  ├─ 动机不是功能——它"附着"在功能之上                       │
│  ├─ 同样的功能可由不同动机驱动                              │
│  ├─ 同样的动机可驱动不同功能                                │
│  └─ 普罗普原文：动机"易变"但不"随意"                       │
└─────────────────────────────────────────────────────────────┘
```

### 8.2 研究原则（基于普罗普原文）

| 原则 | 普罗普原文表述 | 操作要点 |
|------|----------------|----------|
| **归纳优先** | "由手头的材料出发，导出结论" | 先分析后总结 |
| **严格演绎** | "故事研究必须严格遵循演绎法" | 严格按功能分类 |
| **功能独立** | "功能必须独立于实现方式及角色" | 不因上下文改变判断 |
| **关系优先** | "对若干要素之间联系的研究，远比对单个要素的研究更为重要" | 关注成对关系 |
| **后果界定** | "按功能的后果来界定功能"（第四章同化） | 看动作导致什么 |
| **跨文化普适** | "一切神奇故事在结构上属于同一个类型" | 不强求文化差异 |
| **不穷尽分类** | "不必将所有实例系统化" | 品种分类只需枚举几种 |
| **材料自停** | "若发觉所考察的新故事并未带来新功能，便可以停止" | 100篇故事足够 |
| **角色命名自由** | "角色命名与属性完全自由" | 角色不进入功能分析 |

└─────────────────────────────────────────────────────────────┘
```

### 9.3 判定原则表

| 判定维度 | 新功能的标准 | 新品种（实现方式）的标准 |
|----------|---------------|--------------------------|
| **频率** | 反复出现于多篇故事 | 可仅出现1-2次（甚至永不出现） |
| **关系** | 与其他功能形成固定成对关系 | 无法形成新固定关系 |
| **位置** | 在所有出现中位置一致 | 位置随其他功能变化 |
| **后果** | 改变行动进程 | 不改变，仅是同一功能的不同实现 |
| **目的** | 维持形态学研究 | 仅为描述丰富性 |

> **核心原则**（普罗普立场）：**功能尽量少，品种不要无限扩展**。当新品种在大量故事中反复出现、且与其他品种形成固定的成对关系时，才考虑提升为独立功能。

## 十一、方法论要点速查

| 问题 | 普罗普原文立场 |
|------|----------------|
| **功能是什么？** | 角色的一个动作，从它对行动进程的意义出发来界定 |
| **品种是什么？** | 功能的实现方式，简短下标即可 |
| **角色是什么？** | 承担功能的具体行动者，按"行动圈"独立分析 |
| **辅助要素是什么？** | 衔接要素§、三重化:、动机，独立于功能 |
| **如何提取功能？** | 找谓语，按对行动进程的意义界定 |
| **如何确定品种？** | 简要标注实现方式，不必严格系统化 |
| **轮次是什么？** | 从起点到终点的完整发展过程 |
| **如何判断多轮次？** | 新的匮乏/加害 = 新的轮次 |
| **功能与角色如何分离？** | 功能是谓语，角色是主语，二者严格分开 |
| **如何处理同化？** | 按后果界定功能，不是按形式 |
| **如何处理新功能？** | 频率→关系→位置→决定提升还是归入品种 |
| **如何处理倒置？** | 是另一种序列，不破坏规律 |
| **偏差算什么？** | 能被图式吸收为"波动"，否则需解释 |
| **如何处理功能关系？** | 必然配对/相对依赖/自由组合三类 |
| **如何处理文化差异？** | 通过角色实例和属性表达，不进入功能 |
| **材料何时停止？** | 不再带来新功能时停止（100篇足够） |
