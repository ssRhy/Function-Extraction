```

1. 【3 步流水线】Story → Observation → Function

   └─ 远超 5 篇前人（最全面）
```

### 4.2 需要补充的 5 个关键点

#### **补充 1：明确"理论继承 + 创新"的论文贡献段落**

```
【段落 1：理论继承】
"本研究的理论起点是 Propp (1928) 的形态学理论，并继承 Finlayson
 (2012, 2016) 的核心算法框架：跨故事类比合并（Analogical Story

 将 15 个俄语童话扩展到 100+ 个中文故事。"

【段落 2：方法创新】
"在前人工作的基础上，本研究提出三大创新：
 (1) 用 LLM 替代人工标注（解决 Finlayson 2017 的标注瓶颈）；
 (2) 设计开放域 Function Ontology（超越 Propp 31 固定分类）；
 (3) 实现 Function Ontology 的可演化机制（解决 5 篇前人论文

【段落 3：跨文化意义】
"最后，本研究将研究对象从俄语童话扩展到中文网文，

```

#### **补充 2：嵌入 Finlayson 的 "3 维度" 判断规则**

```
【三维度的来源】
Finlayson 2012/2016 在 ASM 算法的 merge rules 中明确：
  1. 事件语义（WordNet + PropBank）
  2. 参与者角色（Propp 7 角色）
  3. 故事位置（相对位置）

这 3 维度是 Propp 自己描述的方法 → 我们可以直接继承

【添加到的 Observation Schema】
在我们的 Observation 字段后增加：
  - 「Narrative Position」: relative_position_in_story（0-1）
  - 「Participant Roles」: 角色标签（hero / villain / donor / helper 等）

这样 LLM 在判断 Function 时就有 3 维度可比（语义+角色+位置）
```

#### **补充 3：建立 "Propp 31 vs 开放 Ontology" 的对比基准**

```
【建议】增加一个 baseline 实验
实验目的：验证开放 Ontology 是否能 "覆盖" Propp 31 功能

步骤：
  1. 准备 15 个俄语童话（Finlayson 2017 公开数据集）
  2. 系统运行这套俄语童话
  3. 把得到的 Function 与 Propp 31 对比
  4. 计算 "重合度"（Hungarian matching）

预期结果：
  - 8 个核心功能（A、HI、W 等）应该被识别出来
  - F1 > 0.7（Finlayson 2016 基准）
  - 验证方法可迁移到俄语童话

价值：
  → 直接可与 Finlayson 2016 的 0.714 对比
  → 证明方法 "至少达到前人水平"
```

#### **补充 4：吸收 4 预测器组合经验**

```
【Valls-Vargas 2016 用 4 预测器组合】
  1. k-NN：基于语义的最近邻
  2. Markov Chain：基于序列的上文
  3. Cardinality：基于该功能预期出现次数
  4. FSA：基于 Propp 31 转换规则

【改造为 LLM 时代的 4 个判断 Agent】
  1. 【Semantic Sim Agent】
     与现有 Function 定义做语义相似度比较
     对应 k-NN
  2. 【Context Agent】
     考虑该 Observation 在故事中的位置（前后文）
     对应 Markov Chain
  3. 【Frequency Agent】
     检查 Function 在训练集的出现频率
     对应 Cardinality
  4. 【Transition Agent】
     检查前后功能是否符合 Propp 转换规则
     对应 FSA

最终输出 4 个预测结果的 ensemble
```

#### **补充 5：增加 "LLM 评估 LLM" 的基准**

```
【5 篇前人论文的盲点】
他们评估 Propp 使用的是人工标注（人工对人工）

【我们的创新】LLM 评估 LLM（自动对自动）

实验设计：
  1. 让 LLM-A 产生 Function Ontology
  2. 让 LLM-B 独立评估该 Ontology 的 "理论合理性"
  3. 让 LLM-C（独立会话）也做评估
  4. 检验 A、B、C 的一致性

价值：
  → 解决 5 篇论文 "无自动评估" 的痛点
  → 类似 LLM-as-a-Judge 范式
  → 可在论文中作为 "评估方法创新"
```

## 7. 论文 Introduction 段落模板（可直接用）

```
【第 1 段：理论起点】
民间故事的叙事结构研究始于 Propp (1928)，他通过分析 100 个俄语童话
归纳出 31 个基本功能（Function）。这一理论首次把叙事结构形式化，
成为后来的结构主义和叙事学的基础。

【第 2 段：前人工作】
Propp 形态学的计算化研究始于 Riedl (2010)，他用 IPOCL 规划算法把
31 功能形式化为可计算问题。Finlayson (2012, 2016) 首次从带语义标注的
15 个俄语童话中以 ASM 算法（修改自 Model Merging）无监督学习 Propp
功能；最佳情况的 Rand Index 达 0.714，其中 HI、EF、A、W 三个核心功能
F1 > 0.8。Finlayson (2017) 详细报告了支撑该工作的 18 层人工标注，
并公开数据集。Valls-Vargas 等 (2016) 提出监督学习方案，在 34 类功能
分类上达 0.281 准确率。

【第 3 段：前人局限】
然而，这些工作面临三个共同局限：
(1) 18 层人工标注耗时 10 个月+，成本约 $125K，扩展性差；
(2) 目标 ontology 固定为 Propp 31 功能，无法发现新功能；
(3) Function 集合是静态的，没有演化机制（MATCH/MERGE/SPLIT）

【第 4 段：本文创新】
本研究针对上述局限，提出基于 LLM 的 Propp 形态学扩展方法：
(1) 用 LLM 替代人工标注（解决标注成本瓶颈）；
(2) 设计开放域 Function Ontology（超越 Propp 31 固定分类）；
(3) 实现 Function 演化机制（静态集合 → 动态本体）；
(4) 在中文网文上验证跨文化可迁移性。

【第 5 段：本文贡献】
本文贡献如下：
· 第一个用 LLM 替代人工标注的 Propp Function 学习系统；
· 第一个支持 Function Ontology 演化的开放域框架；
· 第一个跨文化（中文 vs 俄语）Function 比对研究。
```

## 10. 我们的优势 vs 风险

### 10.1 优势

| 维度 | 传统方法（5 篇） | 我们的 LLM 方法（优势） |
|---|---|---|
| 数据规模 | 15 个故事 | 100+ 故事 |
| 标注成本 | 10 个月+12 人+$125K | 几天+人工 review |
| 功能识别 | 8 个（F1 ~0.7） | 14+ 个（F1 预期更高） |
| 多语言 | 英文翻译（俄语原版） | 中文/任意语言 |
| 可扩展性 | 不 scalable | 高 |
| 领域适应 | 需重新标注 | 通过 prompt 调整 |

### 10.2 风险

| 风险 | 说明 | 缓解策略 |
|---|---|---|
| LLM 幻觉 | 可能生成不存在的功能 | 限定候选功能集（参照 Finlayson 8 个） |
| 评估不一致 | LLM 边界模糊 | 用区域 F1 而非严格 F1 |
| 小样本 | 民俗故事稀缺 | 数据增强（同一故事多次 prompt） |
| 跨语言 | 中英文表达差异 | 先试点小规模验证 |
