### A. 故事的组合方式

至此，故事的主要要素已被指出，若干附属特征也已澄清，我们便可以将文本分解为其组成成分了。

首先，这里便产生了“故事”究竟意味着什么的问题。

从形态学上说，一篇故事（сказка）可以称为：从加害（A）或匮乏（a）出发，经过若干中介功能，直至婚姻（W*），或者直至被用作结局的其他功能。终端功能有时是一种奖赏（F）、一种获得或一般而言对不幸的消除（K）、从追捕中的逃脱（Rs），等等。这一类型的发展过程，我们称之为**轮次**（ход）。每一项新的加害行为、每一项新的匮乏，都造成一个新的轮次。一篇故事可以包含若干轮次；在分析一个文本时，首先必须确定它由多少个轮次组成。一个轮次可以直接接续另一个轮次，但它们也可以相互交织：一段已经开始的发展过程暂停下来，而一个新的轮次被插入。挑出一个轮次并不总是容易的事，但始终可以做到完全精确。然而，即使我们有条件地把故事界定为一个轮次，这仍然不意味着轮次的数量恰好与故事的数量相对应。平行、重复等专门手法，会导致一篇故事由若干轮次组成的情形。

因此，在我们着手解决“如何区分包含一篇故事的文本与包含两篇以上故事的文本”这一问题之前，让我们先看一看——不论一篇文本中所含故事的数量如何——轮次是以何种方式相互结合的。

轮次的结合方式可以如下：

1. **一个轮次直接接续另一个轮次**。这种结合的一个大致图式为：

   ```
   I.  a  W*
   II. A  W²
   ```

2. **一个新的轮次在第一个轮次结束之前便已开始**。行动被一段插曲式的轮次所打断。在插曲完成之后，第一个轮次的完成也随之而来。图式为：

   ```
   I.   ↑ G K W*
   II.  a K
   ```

3. **一段插曲本身又可以被另一段插曲所打断**，由此可以产生相当复杂的图式。

4. **一篇故事可以同时以两项加害行为开始**，其中第一项可以先于第二项被完全消除。若英雄被杀，而且一种魔法媒介被从他那里夺走，那么首先消除的是凶杀这一项，然后才是盗窃这一项。

   ```
   I.     K*
   A
        II.   K*
   ```

5. **两个轮次可以有一个共同的结局**。

6. **有时一篇故事中包含两位寻找者**（参见故事第 155 号《两个士兵之子伊万》）。两位英雄在第一个轮次的中途分开。他们通常在路标处凭预兆分别。这一路标起到一种分离的作用。（路标处的分别，我们将以符号 **<** 表示。）

   有时，路标不过是一种单纯的附属物。）在分别之时，两位英雄常常相互赠予一件物品：一种信物（一把勺子、一面镜子、一块手帕）。我们将信物的传递以符号 **Y** 表示。这类故事的图式为：

   ```
   I.   < Y
   II.  ...
   III. ...
   ```

以上便是轮次相互结合的主要方式。问题随之提出：在何种条件下，若干个轮次构成一篇单一的故事；何时我们面对的是两篇或多篇故事？

在此首先应当说明：**轮次的结合方式本身并不产生任何影响**。并不存在明确无误的标志。但可以举出若干较为清楚的情形。

在以下情形中所面对的是一篇单一的故事：

1. 若整篇故事仅由一个轮次组成。
2. 若故事由两个轮次组成，其中一个以肯定结束，另一个以否定结束。例如，第一轮：继母把继女赶出家门；父亲把她带走；她带着礼物归来。第二轮：继母又把自己的女儿们打发出去；父亲把她们带走；她们归来时受到惩罚。
3. 整个轮次发生三重化时。一条龙劫走一位少女。第一轮与第二轮：哥哥们相继出发去寻找她，都陷入困境。第三轮：最小的弟弟出发，救出少女和两位哥哥。
4. 若一种魔法媒介在第一轮中获得，但要到第二轮中才被使用。例如，第一轮：兄弟们离家去为自己获取马匹。他们得到马后归来。第二轮：一条龙威胁一位公主。兄弟们再次出发，他们借助这些马的帮助而达到目的。这里显然发生了这样的情形：通常置于故事中段的“获得魔法媒介”，被移到了主要的纠葛（龙的威胁）之前。在“获得魔法媒介”之前，有一个未受动机的“匮乏意识”——兄弟们忽然想要马，从而挑起一场寻找，即一个轮次。
5. 我们同样面对一篇单一的故事——如果在不幸被彻底消除之前，忽然感到某种缺少或匮乏，由此挑起一场新的寻找（即一个新的轮次），但并不构成一篇新的故事。在这些情形中，需要的是一匹新的马、装着科谢伊之死的蛋等等；这同时为新的发展提供了开端，而已经开始的发展则暂时停顿。
6. 若两项加害行为同时出现于纠葛之中（驱逐继女并对其施咒，等等），我们面对的也是一篇单一的故事。
7. 在第一轮中包含屠龙、第二轮以兄弟们夺走战利品、把英雄扔入深渊等等开始；然后随之出现 L 以及难题。这一发展过程，在我们逐项列举故事的全部功能时已变得清晰可见。这是故事最完整、最完美的形态。
8. 在路标处分别的英雄们的那种故事，也可以被视为整一（цельные）的故事。但应当注意，每一位兄弟的命运都可能构成一篇完全独立的故事，因此这一情形或许应被排除在“整一故事”的范畴之外。

在所有其他情形中，我们面对的是两篇或多篇故事。在界定“双重故事”时，必须不为极短的轮次所迷惑。尤其简短的是那些包含“毁坏庄稼”与“宣战”的轮次。一般而言，毁坏庄稼占据一种颇为特殊的位置。在多数情形下，立刻便可以看得出：毁坏庄稼的那个角色在第二轮中所起的作用大于在第一轮中，而通过毁坏庄稼，他只是被引入而已。例如，在故事第 105 号中，那匹偷干草的母马在后来是赠予者（也可参看故事 186、187）。在故事第 126 号中，小铜人是以一只偷谷的小鸟的形式被引入的；它与故事 123、125 中的那个小铜人相当。（“那只小鸟——就是小铜人。”）但以角色登场为依据对故事作划分，是不可能的。否则，我们也许可以说，每个第一轮只是为后一轮作准备并引入角色。毁坏庄稼与捉住小偷，从理论上说，是一篇完全独立的故事。但在多数情形下，这种轮次被视为引介性的。

### B. 一个故事的分析示例

知道轮次如何分配，我们便可以将任何一篇故事分解为它的组成成分。我们记得，角色的功能是基本的组成成分。其次，是衔接要素；再次，是动机。角色登场的方式（龙的飞临、与一位女巫的相遇）占据一种特殊的位置。最后，是属性要素或附属物——例如女巫的小屋或她那根由泥做的腿。这五类要素不仅界定了故事的结构，也界定了故事的整体。

让我们尝试把一篇故事彻底地——逐字地——加以分解。作为例子，我们将挑选一篇简短的单轮次故事——我们材料中最短的一篇。较为复杂的故事的示例性分析，则置于附录二，因为大体而言，那些分析只是为专家所重视。

### C. 分类问题

前文已经描述了按“情节”对故事进行分类所遭到的失败。让我们利用我们的若干推论，按结构特征来进行分类。

这里必须分出两个问题：（1）把“神奇故事”这一类与其他类故事相分离；（2）对神奇故事本身进行分类。

神奇故事在结构上的稳定性，允许我们对之作一个假设性的界定，其表述可以是这样的：神奇故事是以上述各项功能以各种形式的恰当交替为骨架而建构的，在每篇故事中有些功能缺失，另一些则重复出现。按这一界定，“神奇”（волшебный）一词便失去了其本来的含义，因为人们很容易想象一种以完全不同的方式建构出来的奇妙、幻想的故事。（比较安徒生与布伦塔诺的若干故事，或歌德的龙与百合的故事，等等。）反之，非神奇的故事也可以按所引图式来建构。相当数量的传说、零星的动物故事以及个别中篇小说，便呈现同样的结构。因此，“神奇”一词应当由另一词来取代。找到这样一词十分困难，我们姑且让这些故事保留其旧称。这一名称可以在与其他类的研究结合起来之后加以更改，那时就有可能创建一套术语。神奇故事可以被称为**服从于七角色图式的故事**。这一名称极为准确，却非常笨拙。若从历史观点来界定这一类故事，那么它们便配得上那个古老的、如今已被废弃的名称——“神话故事”。

当然，这样来界定这一类，要求事先进行分析。不应当期望对某一特定文本的分析可以快速而轻易地完成。一篇文本中不清楚的某一要素，在另一篇平行或不同的文本中往往非常清楚。但凡在没有任何平行文本之处，那篇文本便依然是不清楚的。对一篇故事进行正确的分析，并不总是轻而易举的。这需要一定的经验与技巧。确实，俄罗斯故事集中的许多故事可以被轻而易举地分解。然而，这一工作由于下面这一点而变得复杂：未受污染的故事结构只为农民阶层——而且是那种较少受到文明接触的农民——所特有。各种各样的外来影响都会改变故事，甚至使它变得腐败。一当我们越出纯粹原初故事的边界，复杂性便随之开始。在这一点上，阿法纳西耶夫集是一份令人惊喜的好材料。但格林兄弟的故事，虽然就总体而言也呈现出同样的图式，所呈现的却是一种不那么纯粹、不那么稳定的形式。对一切细节作出规定是不可能的。还必须记住：正如在一篇故事内部各要素发生同化一样，整个体裁也会发生同化并相互掺杂。于是有时会形成极其复杂的集合体，我们这一图式的诸成分便作为插曲进入其中。还应当指出：若干极为古老的神话也呈现出类似的结构，其中有些神话以一种惊人的纯粹形式呈现出这种结构。显然，神话是我们可以追溯故事的领域。反之，同样的结构，例如也为某些骑士小说所呈现。这或许也是一个可以追溯到故事的领域。详细的比较研究是一项留给未来的任务。

为了说明若干动物故事也是以类似方式建构的，我们考察一下《狼与小羊》（阿法纳西耶夫故事第 53 号）。这篇故事为我们提供了：一个初始情境（山羊与小羊们）、一位长者的离家外出、一道禁令、加害者（狼）的欺诈性的劝说、对禁令的违犯、对家庭成员的劫持、不幸的传达、一次寻找、对加害者的消灭（一处与难题发生同化的十分有趣的实例：山羊向狼提议跳过一道深沟；可参看故事第 137 号：公主向沙皇提议用一根杆子跨过那道沟）。¹⁾ 对狼的消灭同时也就是对他的惩罚。被劫的小羊们被救回，归来随之完成。因此，这篇故事应当被排除在动物故事这一类之外。它给出如下图式：

```
γ δ¹ A¹ B¹ K¹ ↓ U *
```

由此，通过运用**结构特征**（структурные признаки），某一类故事可以与另一些类被绝对准确、客观地加以区分。

接下来我们必须把故事在其本质上加以分离。为了避免逻辑上的错误，我们应当指出：一种正确的分类可以按三种方式完成：（1）按同一种标志的不同品种（落叶树或针叶树）；（2）按某一种标志的有无（脊椎动物 vs. 无脊椎动物）；（3）按互相排斥的标志（两趾动物与啮齿动物之于哺乳类）。在同一种分类方法的范围内，分类的方式只能按属、种、变种或者其他等级差别来变化，但每一等级的差别都要求一致性与方法的统一。

若现在审视我们的图式（在稍后引出），人们或许会怀疑：是否有可能按互相排斥的标志进行分类？乍看似乎不可能，因为没有任何一种功能排斥另一种功能。但若更仔细地加以考察，我们便会看到：有两对这样的功能，它们在一个单一的轮次中如此罕见地出现，以至于它们的相互排斥可以被视为规律，而它们的结合则被视为对规律的违背（然而，正如我们以后将看到的，这并不与我们关于故事在类型学上的统一性的论断相矛盾）。这两对便是**与加害者的搏斗及对其的胜利**（H—I），以及**难题及其解答**（M—N）。在 100 篇故事中，第一对出现 41 次，第二对出现 33 次，二者被合并于一个轮次之中者有 3 次。我们进一步看到：也有不包含这些功能的轮次。于是，四类立即形成：通过 H—I 发展的，通过 M—N 发展的，通过 H—I 与 M—N 共同发展的，以及不包含这二者之中任何一对的。

然而，故事的分类由于以下事实而变得极其复杂：许多故事由若干轮次构成。此刻我们讨论的是单轮次的故事；暂时我们继续细分单轮次的故事，稍后再回到复合型的故事上来。

进一步的细分，便不能再按纯粹的结构特征来进行，因为只有 H—I 与 M—N 是互相排斥的，而其余的功能则都不是互相排斥的。因此，必须选取一种对所有故事都是不可或缺的单要素，并按其不同的品种进行细分。A（加害）或 a（匮乏）是仅有的这种不可或缺的要素。进一步的分类可以按这些要素的品种来进行。因此，每一类的开头将出现“关于劫持人”的故事，然后是“关于偷窃护符”的故事，等等，依次贯穿 A 这一要素的一切品种。接下来便是带有 a 的故事——即“关于寻找新娘”的故事、“关于寻找护符”的故事，等等。可以反对说：以这种方式，两个开篇相同的故事会因它们之中是否包含（例如）难题而落入不同的类。这的确会发生，但这并不构成对我们分类之正确性的反驳。包含 H—I 的故事与包含 M—N 的故事，本质上是不同形态的故事，因为这些特征互相排斥。某一要素的有无，是它们的基本结构特征。在动物学中，情形正好相同：鲸鱼不属于鱼类之列，因为它用肺呼吸，尽管它在外观上极像鱼；鳗鱼则归入鱼类之列，尽管它看起来像蛇；马铃薯归入“茎”的一类，尽管人人都把它当作根，等等。这是一种按结构性的、内在的特征进行的分类，而不是按外在的、可变化的特征进行的分类。

进一步的问题在于：对于由多个轮次构成的故事——即包含若干项加害、每一项都各自发展的故事——应当如何处理？

这里的出路只有一条：就每一个多轮次的文本，应当指出其第一轮是这样这样的，第二轮又完全是另一种。没有其他解答。或许这种方法笨拙而不方便，尤其是当我们希望编制一份简明的分类表时，但在本质上，它既是合乎逻辑的，也是正确的。

由此，我们似乎得到四种类型的故事。这是否与我们关于一切神奇故事完全统一的论断相矛盾呢？如果 H—I 与 M—N 在一个轮次中互相排斥，这是否意味着我们面对的不是一种而是两种确定的基本故事类型呢？不，情况并非如此。如果我们仔细考察那些由两个轮次构成的故事，我们便会看到：若一个轮次包含一场搏斗而另一个轮次包含一道难题，那么搏斗总是出现在第一个轮次中，难题则出现在第二个轮次中。这些故事给出了第二轮的典型开端——即把伊万扔入深渊之类。对于这类故事，两轮次的结构是典型的。这是一篇由两个轮次构成的故事，是一切故事的基本类型。它可以被轻易地分为两部分。兄弟们引入了纠葛。若兄弟们不是在开头便被引入，或者他们的作用大体上是有限的，那么故事可能以伊万快乐归来（即第一轮的结束）而结束，第二轮便无须随之而来。由此，前半部分便可以作为一篇独立的故事存在。另一方面，后半部分也是一篇完成的故事。只要以其他的加害者替换兄弟们，或者干脆以寻找新娘为开头，我们便得到一篇可以通过难题而发展的故事。因此，每一轮都可以独立存在，但只有两个轮次的结合才产生一篇完整的故事。或许在历史上曾有过两种类型，各自有其历史；在遥远的某一时代，这两种传统相遇并融合为一个形态。但是当我们谈论俄罗斯神奇故事时，我们必须说：今天这是一篇故事，我们这一类的所有故事都可以追溯到它。

### D. 特殊结构形式与总体图式的关系

让我们逐一考察我们故事中各种结构的性质。

1. 若将所有包含“搏斗—胜利”的图式，以及那些仅仅包含对敌人的单纯杀灭而不经搏斗的实例，一一叠加起来，便得到如下图式：

   ```
   α β γ δ A B C↑ D E F G H I K ↓ Pr Rs ° L Q Ex T U W*
   ```

2. 若将所有包含难题的图式一一叠加起来，则得到如下结果：

   ```
   α β γ δ A B C↑ D E F G ° L M J N K ↓ Pr Rs Q Ex T U W*
   ```

将这两个所得图式加以比较，便得到：

```
α β γ δ A B C↑ D E F G    H  I  K ↓ Pr Rs ° L Q Ex T U W*
α β γ δ A B C↑ D E F G °  L  M  J N  K ↓ Pr   Rs Q  Ex T U W*
```

由此可以清楚地看到：搏斗—胜利（H—I）与难题及其解答（M—N）在与其他功能的序列关系上彼此相当。在这些功能之中，只有“未被识别的抵达”与“冒牌者的冒功”（°—L）所占据的位置有所改变——它们紧随搏斗，却先于难题出现（即：装扮成厨子的王子，挑水夫冒充胜利者；伊万住在一个手艺人家里，兄弟们冒充猎获战利品的人）。

进一步可以看到：包含难题的轮次，最常是第二轮、第三轮或重复的轮次，而极少（仅一次）出现在第一轮。若一篇故事由两个轮次组成，那么包含搏斗的轮次总是先于包含难题的轮次。由此我们得出结论：**包含 H—I 的轮次是典型的第一轮，包含难题的轮次则是典型的第二轮或重复轮次**。它们各自也可以独立存在，但结合总是按上述顺序发生。理论上，当然相反的结合也是可能的；但在这些情形下，我们总会面对两篇故事的一种机械性的拼合。

3. **同时包含这两对的故事**呈现出如下图景：

   ```
   α β γ δ A B C↑ D E F H I K ↓ ° L M N Q Ex U W*
   ```

   这里功能 H—I 同样可见于功能 M—N 之前。功能 L 位于二者之间。

   所考察的这三种情形，还不足以就“追捕在上述结合中是否可能”给出看法。在所有被考察的实例中，追捕都不存在。

4. 若将所有**既不包含任何形式的搏斗、也不包含难题**的图式一一叠加起来，便得到如下结果：

   ```
   α β γ δ A B C↑ D E F G K ↓ Pr Rs Q Ex T U W*
   ```

若把这一图式与上述各图式相比较，便可看出：这些故事也不呈现任何特殊的结构。

于是，一切材料的图式都可以归入如下可变的图式之中：

包含 H—I 的轮次沿上支发展；包含 M—N 的轮次沿下支发展；同时包含两对的轮次先沿上半部分发展，然后再沿下支发展下去，并不就此结束；既不包含 H—I 也不包含 M—N 的轮次，则绕过每一支的特有要素而发展。

让我们按这一图式来整理我们的材料。为清楚起见，我们先把所得图式写在同一行上。H—I 与 M—N 既然互不相容，便上下并列书写。（这些图式已被移至附录三。）

这一图式提示了哪些结论呢？第一，它肯定了我们关于神奇故事在结构上完全统一的总体论断。

这一最重要的总体结论，初看起来与我们对故事之丰富性与多样性的观念并不吻合。如前所述，这一结论是颇为出人意料的。它对本著作的作者本人来说也是出乎意料的。这一现象如此不寻常而奇特，以至于在转向更为专门的、形式的结论之前，人们似乎有必要对它多停留片刻。自然，对这一现象的诠释并不属于我们的任务；我们的任务只在于陈述这一事实本身。然而，人们依然倾向于提出这样的问题：若一切神奇故事在形式上都如此相似，这是否意味着它们全都起源于单一的来源？形态学者没有权利回答这一问题。此时他把自己的结论交给历史学家，或者自己应当成为历史学家。我们的回答——尽管以假说的形式——是：这似乎确属如此。然而，关于“来源”的问题不应当以狭隘的地理意义来提出。“单一的来源”并不必然意味着——如某些人所设想的那样——所有故事都来自印度，并从那里传播到全世界，在其传播过程中获得各种形态。单一的来源也可以是一种心理学上的来源。冯特在这一领域已做了许多工作。但在这里我们也必须极为审慎。若以人类想象力在总体上的有限性来解释故事的有限性，那么我们便不会拥有那些不属于我们所给定类别之外的故事，但我们却拥有数以千计的、与神奇故事并不相似的其他故事。最后，这一单一的来源也可以来自日常生活。但对故事所作的形态学研究将表明：故事中属于日常生活的成分是极少的。从日常生活的模式到故事的某些过渡阶段确实存在，这一模式间接地反映于其中。这样的过渡阶段之一便见于那些在日常生活的某一发展阶段上所产生的信仰；而在日常生活与宗教之间、在宗教与故事之间，很可能存在着一种自然的联系。一种生活方式与一种宗教会消亡，而它们的内容则转化为故事。如前所述，故事中包含着如此明显的宗教观念之痕迹，以至于无需历史学的帮助便可以追踪到它们。但由于这一假说从历史的角度更易澄清，我们将举出一个小小的故事与信仰之间的平行例子。故事提供了伊万在空中被载送的三种基本形式：飞马、鸟与飞船。但恰巧这三种形式又代表死者灵魂的载送者：在从事农业和畜牧的民族中以马为主，在狩猎民族中以鹰为主，在海边居民中以船为主。⁵ 甚至弗罗贝尼乌斯还引用了西北美洲“灵魂之船”（Seelenschiff）的观念。由此可以推测：故事构成的一个基本要素——“漫游”——反映了关于灵魂在另一个世界漫游的观念。这种观念，连同其他若干观念，无疑曾在全世界各自独立地产生。文化的交叠与信仰的消亡完成了其余的事。飞马让位于更有趣的飞毯。但我们已经走得太远。我们将这一切留给历史学家去判断。在与宗教的平行研究方面，以及在故事向日常生活的文化与经济层面的进一步渗透方面，对故事的研究仍然非常不足。

以上便是我们整个工作中最一般的、最根本的推论。我们已不再能像斯佩兰斯基那样说：在故事研究中不存在任何概括。这样的概括确实只是一种尝试。然而，若它是对的，它在将来应当引出一系列其他的概括性结论。或许，故事至今仍深深包裹着的那个秘密，将由此逐渐开始展开。

让我们回到我们的图式上来。关于“绝对稳定性”的论断，似乎会被这一事实所推翻——功能的序列并不总是与总体图式所示的相同。仔细审视各图式，便会发现若干偏差。尤其可以观察到：**要素 DEF 常常出现在 A 之前**。这是否破坏了规律？不，因为这并不是新的序列，而是一种**倒置的**（обращённый）序列。

普通的故事，例如先给出不幸，然后获得消除它的助手。倒置序列则先给出获得助手，然后再给出被他消除的不幸（要素 DEF 在 A 之前）。另一例：通常先给出不幸，接着是离家（ABC↑）。倒置序列则先给出离家——离家通常并无目的（“去看看人，开开眼界”，等等）；后来英雄已经在路上，才得知不幸的消息。

若干功能可以互换位置。在故事 93 与 159 中，与加害者的搏斗只在追捕之后才发生。

相认与揭穿、婚姻与惩罚也可以互换位置。在个别功能之中，魔法媒介的传递有时出现在英雄离家之前。这些便是由父亲所赠予的木棒、绳索、狼牙棒，等等。这一类传递最常出现在 A³（毁坏庄稼）的情形中，但也可以见于其他纠葛之中，并丝毫不决定与通常类型的赠予者相遇的可能性。相对于其位置而言，**最不稳定的功能是 T（变形）**。从逻辑上讲，它最恰当的位置要么在惩罚冒牌英雄之前或之后，要么在成婚之前——它确实最常出现在那里。所有这些偏差，都不改变关于故事在类型学上的统一与形态学上的亲缘关系的推论。这些只是波动，而不是一种新的构成体系或新的轴线。当然，也存在若干直接违反的情形。在零星的故事中，那种违反是相当显著的（164、248），但更细致的考察将表明这些故事属于滑稽故事。伴随诗体向笑剧转化而发生的这种位置的置换，必须被视为一种瓦解的结果。

零星的故事相对于基本类型呈现出一种不完整的形态。任何一篇故事中都有一项或另一项功能缺失。若一项功能缺失，这丝毫也不影响故事的结构——其余的功能保持着各自的位置。常可以根据若干残迹看出：这种缺失其实是一种省略。

准备部分的功能也完全服从于这些结论。若将我们材料中的全部实例一一写出，其总体上便会呈现我们在前文列举功能时所指出的同一序列。然而，对这一部分的研究因以下情形而变得复杂：这一部分的七项功能永远不会同时出现在同一篇故事中，而它们的缺失永远无法被解释为省略。它们本质上是互不相容的。在此可以观察到：同一现象可以由若干手段引出。例如，为了让加害者制造不幸，讲述者必须把英雄或受害者置于某种无助的状态。最常见的情形是他必须与父母、长者或保护者分开。这可以由以下方式实现：英雄违犯一道禁令（不顾禁令而离家）；或者英雄独自出门散步，等等（β³）；或者通过加害者诱骗他去海边或把他引入林中等等而实现。因此，若故事为这一目的而使用两对中的一对——γ—δ（禁令—违禁）或 η—θ（欺骗—顺从欺骗），则常常无须使用另一对。关于把信息传递给加害者，也可以通过英雄违犯禁令而达成。因此，若准备部分中使用了若干对，我们总能期待一种双重的形态学意义（在违犯禁令时，英雄把自己交给加害者，等等）。对这一问题的详细澄清需要以更多材料为依据的进一步分析。

在考察各图式时还可以提出一个十分重要的问题：一种功能的若干品种，是否必然与另一种功能的相应品种相联系？各图式以如下方式回答这一问题：

1. **存在这样一些要素，它们毫无例外地总是与彼此相对应的品种相联系**。这些是若干对其两半之间严格成对的要素。于是 H¹（在旷野中的搏斗）便总是与 I¹（在旷野中的胜利）相连；而与例如 I³（在牌局中获胜）的联系则是完全不可能且毫无意义的。以下若干对的所有品种，都彼此永久地相连：禁令与其违犯；试图探知某事与信息的传递；加害者的欺骗（诈骗）与英雄对它的反应；搏斗与胜利；印记与相认。

   除了这些“各品种始终彼此相连”的对之外，还有若干对，对之我们可以就其中若干品种作同样的论断。于是，在加害及其消除的范围内，便有若干种稳定的联系——凶杀与复活、施咒与解咒，以及其他若干种。在追捕与解救的若干品种之中，伴随着迅速变为动物的追捕，总与一种相应的解救形式相连。由此，我们发现若干要素的存在，其品种由于逻辑的、有时也是艺术上的必然性而稳定地彼此相连。

2. **存在这样一些对，其中一半可与相应一半的若干品种（但不是全部）相联系**。劫持可以与一种直接的反劫持（K¹）相连；与通过两位或更多助手的夺回（K¹、K²）相连；与凭借魔法性质的瞬时返回的夺回（K⁵）相连，等等。完全相同地，直接追捕可以与凭借单纯飞奔的解救相连，与凭借奔逃并投下梳子的解救相连，与被追捕者变成教堂或井、与之藏匿于某种地方相连，等等。然而，不难看到：一对之中的某一项功能，常常可以引出若干种反应，但每一种反应只与那一种引出它的具体形式相绑定。于是，“投下梳子”总与“直接追捕”相连，而“直接追捕”则并非总与“投下梳子”相连。在这一点上，便出现了若干只能够单方面或双方面地加以替换的要素。我们此刻不拟详述这一区别。我们只指出第三章中已考察过的 D 与 F，作为可以进行极广泛双面替换的要素。

   然而，必须指出：这些依赖关系的规范，虽然本身显而易见，却有时被故事所违犯。加害及其消除（A—K）彼此之间被一段漫长的故事所隔开。在故事的进程中，讲述者会失去故事的线索，于是可以看到：要素 K 有时并不完全与最初的 A 或 a 相吻合。故事仿佛走了调。伊万出发去找一匹马，归来的却带着一位公主。这一现象对研究变形是不可多得的材料：讲述者不是改变了开端，便是改变了结局；从类似的比较中，可以推导出若干变化与替换的方法。我们也遇到一种与“走调”相似的现象——故事的前半部分没有引出惯常的反应，或者代之以一种完全不同的、对于故事的常态而言并不寻常的反应。在故事第 260 号中，对一位男孩的施咒之后，并未随之出现解咒，他于是终身都成了一只小山羊。⁶

3. **其余一切要素，包括那些实际成对的要素，都可以自由地相互连接，而不违背逻辑或艺术的价值**。容易看出：在某一篇故事中，“劫持人”并不要求随后的“循血追踪”必须被替换为“飞奔”或“道路的指示”。同样地，在夺取护符时，也没有理由强迫英雄不是接受空中追捕的折磨，而是接受企图谋杀的折磨。如此，这里通行的是**完全的自由与互相替换**的原则。在这一点上，这些要素与那些像 H—I 那样始终必然彼此相连的要素正好相反。我们只是就这一原则而言。然而，人们对这种自由利用得并不多，真正存在的连接的数量并不很大。例如，没有任何故事把“施咒”与“呼唤”相连，尽管这一连接在艺术上和逻辑上完全可能。尽管如此，在不自由的原则之外确立自由的原则，意义十分重大。主题的变化与故事的变形，正是通过同一要素的某种形态替换另一种形态而实现的。

此外，这些结论还可以由实验加以验证。我们可以人为地创造出不限数量的新情节。所有这些情节都将反映基本图式，而它们彼此之间却可能并不相似。为了人为地创造一篇故事，我们可以取任何一种 A，然后取一种可能的 B，接着取一个 C↑，然后绝对任取一种 D，再取一种 E，再取一种可能的 F，再任取一种 G，如此等等。在此过程中，任何要素都可以被略去（除 A 或 a 之外），或作三次重复，或以各种形式重复。若随后按故事中可用的角色或按自己的喜好来分配功能，这些图式便鲜活起来，变成了故事。⁶ 当然，还必须顾及动机、衔接和其他辅助要素。把这些结论运用于民间创作，自然需要极为审慎。讲述者的心理以及他的创作心理——作为一般创作心理的一部分——必须独立地加以研究。但完全可以设想：本质上极为简单的我们这一图式的基本、鲜明的若干环节，也起到一种“根部”的心理作用。然而，新的故事将始终只是旧有故事的组合或变体。这似乎是在说：在故事方面，民间并没有创造。这并不尽然如此。我们可以准确地划定民间讲述者从不创造的那些领域，以及他或多或少自由地进行创造的领域。讲述者受到约束、并不创造的有以下几个方面：（1）功能的总体序列，其系列按上述图式发展。这一现象呈现出一个我们无法在此处解释的复杂问题；我们只能陈述事实。它应由人类学以及与之相邻的学科加以研究，唯有它们才能说明其原因。（2）对于那些其品种之间以绝对的或相对的依赖性相连的要素，讲述者无权作替换。（3）在其他情形中，当一项确定的功能被要求时，讲述者不能按属性随意选择若干角色。然而必须指出：这种不自由是高度相对的。例如，若要求功能 G¹（飞行），那么“生命之水”便不能充当一种魔法礼物；而一匹马、一块飞毯、一只戒指（藏着数位青年）、一只小箱子，以及许多其他事物，都可以在这里充当。（4）在初始情境与随后的功能之间，存在着某种依赖关系。在需要或希望使用功能 A²（对助手的劫持）时，该助手必须被纳入初始情境之中。

讲述者在以下几个方面则是自由的：（1）在他所省略或反过来所使用的那若干功能的选择上。（2）在用以实现某项功能的方式（形式）的选择上。如前所述，新异文、新情节、新故事的形成，正以这种方式发生。（3）讲述者在角色的命名与属性上完全是自由的。从理论上说，这里的自由是绝对的。一棵树可以指明道路，一只鹤可以赠予一匹马作为礼物，一把凿子可以窥探，等等。这种自由只是故事所特有的现象。但也必须指出：在这里，民众对这种自由的利用也并不广泛。角色如同功能一样，反复出现。如前所述，这里已经形成了一种特殊的典范（龙是典型的加害者，女巫是典型的赠予者，伊万是典型的寻找者，等等）。典范会变化，但这种变化极少是个人艺术创作的产物。可以确认：故事的创造者很少凭空发明；他从其周围或现实取材并加以改造，使之适合于故事。⁷ （4）讲述者在语言手段的选择上是自由的。这一极为丰富的领域不属于形态学者的研究范围。故事的风格是一种必须单独研究的现象。

### E. 情节与情节、情节与异文的问题

至此，我们一直是从结构的观点来考察故事的。过去我们看到，故事一向是从情节的观点来考察的，我们也不能越过这一问题。但由于对“情节”（сюжет）一词并不存在任何一种被普遍接受的单一界定，我们便有了完全的余地，可以按我们自己的方式来界定这一概念。

故事的全部内容可以用若干简短的短语加以陈述，例如：父母离家走进森林；他们禁止孩子们走上街；一条龙劫走小女孩，等等。所有的谓语都给出故事的**构成**（composition）；所有的主语、宾语以及句子的其他部分，则界定**情节**（theme）。换言之，相同的构成可以成为各种情节的基础。从构成的观点看，劫走一位公主的是龙还是魔鬼、劫走的是神父的女儿还是农夫的女儿，都无关紧要。但这些情形可以作为不同的情节加以考察。我们也承认对“情节”这一概念的其他界定方式，但所给出的这一界定方式对于神奇故事是适用的。

我们应当如何把“情节”和“异文”加以区分呢？比如，假定有一篇故事，其形式为 A¹ B¹ C D¹ E¹ F¹，等等；还有一篇故事，其形式为 A¹ B² C D¹ E¹ F¹，等等；问题是：在保留其他一切要素的情况下，变更一项要素（B），究竟产生了一种新的情节，还是仅仅构成了前一种情节的一个异文？显然，这是一个异文。那么，若有两项、三项或四项要素发生变更，或者有一项、两项或三项要素被略去或被加入呢？问题便由质的问题转化为量的问题。无论我们如何界定“情节”这一概念，“情节与异文之间的区别”都是完全不可能的。这里只能有两种观点：要么每一变更都产生新的情节，要么一切故事都构成同一种情节的不同异文。事实上，两种表述说的是同一件事：整个神奇故事的宝库都应当被视为一条异文的链条。若我们能够展开一幅变形的图景，那我们便可以确信：所给出的全部故事，都可以形态学地从“龙劫公主”的那类故事——从我们倾向于视为基本的形态——演绎出来。这是一个非常大胆的论断，尤其是因为我们并未在本著作中展示变形图景。在这种情况下，拥有非常广泛的材料便十分重要。故事可以被排列成这样的顺序，以致一幅从一种情节向另一种情节逐渐过渡的图景可以变得相当清晰。当然，在某些地方会出现跳跃和空白。人们并未提供一切在数学上可能的形态。但这并不与这一假说相矛盾。让我们记住，故事的采集还不到一百年。开始采集故事的那个时代，故事已经处在解体的过程中。当下不存在新的形态。但无疑曾有过极富成果的、创造性的时代。阿arne 认为，中世纪的欧洲便是这样一个时代。当代某些形态的缺失，并不与总体理论相矛盾——只要我们意识到，故事在其中生机勃勃地存在着的那些世纪，已经无可挽回地为科学所失去。正如我们根据一般的天文学规律来推测那些我们看不见的恒星的存在，我们同样可以假定那些未被采集到的故事的存在。

由此便产生了一项重要的、方法论意义上的应用。

若我们关于故事的极其密切的形态学亲缘性的观察是正确的，那么，这一属故事中的任何单一情节，无论在形态学上还是在发生学上，都不能在不参考其他情节的条件下被研究。一个情节通过按形式的要素替换而变为另一个情节。自然，对某一篇个别故事在它的一切异文之中以及按其全部流传来加以研究，这一任务是极为诱人的。但这一任务在本质上是被错误地设定了。例如，若在某篇故事中出现了魔法骏马、感恩的动物、机智的女子等等，而研究又仅仅在给定的结合中对它们加以考察，那么便有可能：给定结合中的每一项要素都得不到穷尽性的研究。这样一项研究的结论将会是摇摇不定的、不正确的，因为每一项要素也可能在另一种应用中出现，并可能具有其自身的历史。

所有这些要素，都应当首先在其自身中被独立地加以研究，不依赖于它们在这一篇或那一篇故事中的用法。现在，当民间故事对我们来说仍充满奥秘时，我们首先需要的，乃是对每一项要素在整个故事材料中分别加以阐明。奇迹般的降生、禁令、获得魔法媒介、飞行与追捕等等，都是值得独立专著研究的要素。不言而喻，这样的研究不能仅仅局限于故事。其大多数要素都可以追溯到某一种古老的文化、宗教、日常或其他现实上去，这些都必须被拿来加以比较。在分别研究了各项要素之后，便必须进行一种发生学的研究，研究所有神奇故事赖以形成的那条轴线。当然，变化的规范与形式也必须被研究。只有在此之后，才可以着手研究各个情节是怎样形成的，以及它们究竟是什么的问题。

### F. 结语

随着我们的工作结束，剩下的便是给出一个结语。把各项命题重新概括一遍并无必要。它们已被置于本书的开端，整部著作也都贯穿着它们。取而代之，我们可以指出：我们的诸项命题，尽管看似新颖，却已被一位先驱——维谢洛夫斯基——以直觉的方式预见。我们便以他的话语来结束本研究：

> 我们是否可以在这一领域也来考虑关于“典型图式”的问题……这些图式被世代相传，作为一种现成的、能够被赋予新情绪并引出新形态的公式而流传下来？……当代叙事文学以其复杂的情节结构和对外在现实的摄影式再现，似乎使这种问题的提出本身都不再可能。但当这种文学在未来一代眼中变得像古代那样遥远——从史前时代到中世纪，在我们看来似乎依然遥远——当时间的综合、这位伟大的简化者，在掠过现象的复杂性而将之化为退远为点的量值时，它们的线条便会与我们在回顾遥远过去的诗学传统时所揭示的那些线条合而为一——于是，图式化与重复的现象，便将在整个跨度上得到确立。⁸
