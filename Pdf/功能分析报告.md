# 跨文化故事功能分析报告（新方法版 v3.0）

> **分析方法**：严格基于普罗普原文的功能提取方法论（v3.0）
>
> **报告版本说明**：
> - v1.0：基础分析版
> - v2.0：增加七角色行动圈与辅助要素章节
> - **v3.0（当前）**：精简结构 — 删除冗余章节，5 步提取法落地
>
> **结构优化**（v3.0 核心变更）：
> 1. 删除"七角色行动圈"独立章节（已合并到功能提取表）
> 2. 删除"辅助要素"独立章节（§ 和 : 已合并到备注栏）
> 3. 删除"与基本图式比较"独立章节（已合并到图式与配对）
> 4. 保留"动机补遗"作为可选维度（第 3 步未覆盖的新维度）
> 5. 模板套路增加"反向投影"，标记被压缩的维度
>
> **分析目的**：
> 1. 验证功能提取方法论的跨文化适用性
> 2. 验证功能关系的跨文化稳定性（**核心**）
> 3. 识别同化现象（按后果界定功能）

> **分析方法论核心**（基于普罗普第八章D节）：
> "对若干要素之间联系的研究，远比对单个要素的研究更为重要。"

## 新功能提取方法论总结

> **来源**：本章节基于`功能提取方法论_README.md`第八章"研究方法论"，结合本报告 8 个跨文化故事的实际分析经验归纳而成。

### 一、核心立场

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  提取新功能的标准四步操作                                       │
│                                                              │
│  第一步：找谓语（动词）                                       │
│   └─ 从原文中找"谁做了什么"的动作 │
│                                                              │
│  第二步：界定功能（从对行动进程的意义出发）                  │
│   └─ 这个动作在"故事如何向前发展"中起什么作用？            │
│                                                              │
│  第三步：匹配 31 项功能表 │
│   └─ 这个功能在 31 项中是否已有对应？                       │
│   ├─ 有 → 套用现有功能+新品种下标                          │
│   └─ 无 → 触发"按后果界定功能"原则 → 同化或新功能         │
│                                                              │
│  第四步：与基本图式对照                                       │
```

### 二、新功能的三个来源

#### 来源 1：填补缺失——同化原则的核心（占比 ~25%）

普罗普原文第八章 D 节：**"按后果界定功能"**。

```
┌─────────────────────────────────────────────────────────────┐
│  同化的判定三步法 │
│                                                              │
│  问1：这个动作是否承担了"某已知功能的后果"？               │
│       例：猎人剪开狼肚子 → 让被吞者重获自由 │
│       → 与 Rs（解救）的"后果"一致 │
│                                                              │
│  问2：但是它的"形式"与已知品种不同吗？                      │
│       例：普罗普的 Rs 都是"逃脱追捕" │
│       → 此处是"被吞后取出"，形式不同                      │
│                                                              │
│  问3：因此如何标注？                                         │
│       → 仍归为 Rs，但标注为新品种（同化）                   │
│       → 在"同化分析"栏目说明"Rs = 解放，非追捕解救"       │
└─────────────────────────────────────────────────────────────┘
```

**本报告案例**：

| 故事 | 原文 | 表层 | 按后果界定 | 同化为 |
|------|------|------|------------|--------|
| 小红帽 | "猎人剪开狼肚子" | 物理切割 | 被吞者获自由（=解救的后果） | Rs = 解放 |
| 田螺姑娘 | "田螺壳只剩空壳" | 物品消失 | 变形被解除（=T的反面后果） | Pr = T（变形解除）|
| 嫦娥奔月 | "乡亲摆食品祝福" | 仪式行为 | 形成节日（=W*的后续后果） | B = 纪念仪式 |

#### 来源 2：发现新品种——实现形式的扩展（占比 ~10%）

当一个动作**明确属于**某个已知功能，但**实现形式与已有品种都不同**时，记为新品种下标。

```
┌─────────────────────────────────────────────────────────────┐
│  新品种发现的判定法                                            │
│                                                              │
│  前提：动作的"功能"已明确归属 │
│   例：石中剑的"尝试拔剑"= D（资格考验）                 │
│                                                              │
│  问：现有 D 的下标能否覆盖？                                  │
│   D¹ ~ D¹⁰                                                  │
│   └─ 都是"赠予者考验英雄"的形式 │
│   └─ 此处是"由剑考验所有贵族"（剑本身是考验物）          │
│   └─ 既非赠予者考验，亦非临终请求                          │
│                                                              │
│  → 仍属 D 功能，但下标扩展为 D⁷（资格考验）               │
│  → 在品种表标注 │
└─────────────────────────────────────────────────────────────┘
```

**本报告案例**：

| 故事 | 原文 | 功能 | 新品种 | 理由 |
|------|------|------|--------|------|
| 石中剑 | "无人能拔剑" | D | D⁷（资格考验）| 考验物是物品，不是赠予者 |
| 石中剑 | "亚瑟轻松拔剑" | D | D⁸（资格确认）| 考验结果是即时相认 |
| 龟兔赛跑 | "兔子骄傲停下来" | D | D⁶（自我考验）| 主体是英雄自身 |
| 嫦娥奔月 | "嫦娥飞向月亮" | G | G⁸（升天移动）| 方向是向上 |
| 嫦娥奔月 | "亚瑟是真正的国王" | Q | Q⁴（天命相认）| 标志是天生 |

#### 来源 3：真正的新功能（占比 ~5%，几乎不出现）

普罗普的 31 项功能在所有神奇故事中已穷尽。当你"看似"发现新功能时，先做以下检查：

```
┌─────────────────────────────────────────────────────────────┐
│  怀疑是新功能时的检查清单                                      │
│                                                              │
│  ① 这个动作是否真的是"推进故事发展的关键动作"？           │
│     └─ 否 → 是辅助要素（§/:），不是功能 │
│     └─ 是 → 继续                                          │
│                                                              │
│  ② 它能否归到 31 项的某一项？                               │
│     └─ 是（哪怕是同化） → 归入已有功能                     │
│     └─ 否 → 才可能是新功能                                 │
│                                                              │
│  ③ 它是否是一个复合动作（多个功能的合并）？                │
│     └─ 是 → 在备注栏拆分为多个已知功能                     │
│                                                              │
│  ④ 普罗普本人是否在第八章已说明？                           │
│     └─ 大多数"新功能"实为已知功能的变体                   │
└─────────────────────────────────────────────────────────────┘
```

### 三、批量提取的标准流程

```
┌─────────────────────────────────────────────────────────────┐
│  批量故事中提取新功能的标准流程                                │
│                                                              │
│  【第一轮：逐句标注】                                        │
│  ├─ 对每个故事： │
│  │   1. 通读全文，标注起点（∅/a/A）和终点（W*/K*/Rs/T*） │
│  │   2. 逐句提取功能（动词 → 功能 → 角色 → 下标）         │
│  │   3. 填入五列表格：原文/功能/品种/备注/变异 │
│  └─ 暂时不归类，重点是"不漏动作"                           │
│                                                              │
│  【第二轮：跨故事对比】                                      │
│  ├─ 把所有故事的"功能序列"并排放在一起 │
│  │   [故事A] α a A F Pr Rs E W*                            │
│  │   [故事B] α F γ δ G ε η δ :Pr A L D A:G K Rs U K      │
│  │   [故事C] ... │
│  ├─ 找出"反复出现的功能对"：D-E、H-I、A-K、Pr-Rs 等      │
│  └─ 找出"反复缺失的功能"：                                │
│      └─ 例如：很多故事都没有 H-I → 标记为"非战斗型"      │
│                                                              │
│  【第三轮：发现新品种/新功能】                                │
│  ├─ 同一功能内： │
│  │   出现已有品种之外的实现形式 → 新品种下标               │
│  │   例：D⁷（资格考验）、Q⁴（天命相认）                  │
│  └─ 跨功能边界：                                              │
│      动作既像 D 又像 Q → 拆为 D + Q，不是新功能           │
│      动作完全无法归类 → 按后果界定功能（同化原则）        │
│                                                              │
│  【第四轮：图式合成与关系分析】                                │
│  ├─ 把功能序列写成图式                                       │
│  ├─ 标注轮次关系（直接接续/交织） │
│  └─ 分析功能对（必然配对/相对依赖/自由组合）                │
│                                                              │
│  【第五轮：同化现象归纳】                                    │
│  ├─ 把所有"按后果界定"的功能归入"同化分析"表             │
│  ├─ 发现规律：                                               │
│  │   └─ 非欧洲故事同化程度更高                             │
│  │   └─ 极简故事（如寓言）同化最严重 │
│  └─ 同化是"理解非标准故事"的核心机制 │
└─────────────────────────────────────────────────────────────┘
```

### 五、易错的边界情况

#### 边界 1："新功能"往往是复合动作

```
原文："后羿射下九日"
直觉：好像是个新功能"消除自然灾害"
分析：其实是 A（太阳加害） + K（消除加害）= A-K配对
结论：不是新功能，而是已知功能的组合
```

#### 边界 2："辅助要素"伪装成功能

```
原文："妈妈让她走大路"
直觉：好像是个新功能"路线指示"
分析：γ（禁令）已涵盖，"走大路"是禁令的内容
结论：不是新功能，是 γ¹ 的内容
```

#### 边界 3：同一动作的双重身份

```
原文："三人共同抓获加害者"
直觉：可能是新功能"集体行动"
分析：实际是 I（胜利）的实现形式之一
结论：记为 I，但标注"集体形式"
```

### 六、本报告新功能提取实证

下表汇总本报告 8 个故事中所有看似"新功能"的实例，验证**新功能极少出现**这一判断：

| 故事 | "新功能"假象 | 实际判定 | 处理方式 |
|------|--------------|----------|----------|
| 牛郎织女 | "老牛指引"好像新功能 | F⁶（自现/指示）已有 | 套用现品种 |
| 田螺姑娘 | "谢端闯入"是新加害吗？ | A⁵（强制挽留）已有 | 套用现品种 |
|桃太郎 | "桃子裂开出生"是新功能吗？ | T⁵（奇迹出生）已有 | 套用现品种 |
| 小红帽 | "狼先到"是新功能吗？ | Pr⁵（抢先）已有 | 套用现品种 |
| 三只小猪 | "狼吹倒"是新功能吗？ | H⁴（物理力量）| 同化（H ≠ 搏斗）|
| 龟兔赛跑 | "兔子打盹"是新功能吗？ | D⁶（骄傲考验）已有 | 套用现品种 |
| 石中剑 | "拔剑考验"是新功能吗？ | D⁷ D⁸（资格考验/确认）| 新品种下标 |
| 嫦娥奔月 | "嫦娥飞升"是新功能吗？ | G⁸（升天移动）| 新品种下标 |

**结论**：
- 在 8 个故事约 100 个动作中
- **真正的新功能 = 0**
- **新品种下标 = 5 个**（D⁶ D⁷ D⁸ G⁸ Q⁴）
- **同化判定 = 10+ 处**

这就是普罗普方法论的力量：**31 项功能足以覆盖所有故事类型**，剩下的工作只是"按后果界定"和"扩展品种下标"。

### 八、与本报告其他章节的关联

- **七角色行动圈**：新功能提取后，角色分配在新功能上同样适用（行动圈不变）
- **功能关系分析**：新品种下标不影响功能关系，配对规则保持稳定

- **辅助要素**：新功能提取要避免把辅助要素（§/:）误判为功能
